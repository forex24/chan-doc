## 2. 原九项的固定构造障碍

### 2.1 输入与计算

设连续的九个同级完成材料为 `q1` 至 `q9`，端点依次为：

`0 → 100 → 40 → 60 → 20 → 50 → 45 → 100 → 20 → 42`。

暂设每项全价格范围恰为两端点区间。这里的“完成、同级、连续”是输入假设；所属整体、形成角色、分解来源和九段定理适用资格不能由这些数字自动获得。

| 项 | 方向 | 全范围 |
| --- | --- | --- |
| q1 | 上 | [0,100] |
| q2 | 下 | [40,100] |
| q3 | 上 | [40,60] |
| q4 | 下 | [20,60] |
| q5 | 上 | [20,50] |
| q6 | 下 | [45,50] |
| q7 | 上 | [45,100] |
| q8 | 下 | [20,100] |
| q9 | 上 | [20,42] |

首三项核心为 `K1 = [40,60]`。后续同向的 q5、q7、q9 分别与 K1 相交；在当前抽象逐项读法下，相关离开及首返没有严格破坏 K1。与固定原核的相交不同于所有同向材料存在公共交集：这些同向材料的最大低点为45、最小高点为42，公共交集为空。不能把“所有同向项共同重叠”悄悄加成延伸前提。[20 课](../原文/chzhshch-108-plus/108/0424-486e105c010007zw-020.md)给出的中心定理一使用各同向 Z 段与固定原核相交的表述。

### 2.2 不可满足的是哪组构造约束

同时要求以下条件：九项不可拆；覆盖恰好这九项；材料按时间连续；每项不重复分配；需要三个高级完成走势；每个高级走势至少包含三项。

若三走势的项数分别为 n1、n2、n3，则 `n1+n2+n3=9` 且各项不小于3，因此只能是：

`(q1+q2+q3) + (q4+q5+q6) + (q7+q8+q9)`。

三组的三项交集分别为：

| 固定组 | 三项交集 |
| --- | --- |
| q1—q3 | [40,60] |
| q4—q6 | [45,50] |
| q7—q9 | 空集：max(45,20,20)=45 > min(100,100,42)=42 |

根据 [18 课](../原文/chzhshch-108-plus/108/0419-486e105c010007t8-018.md)，完成走势必须包含本级中枢，高级走势至少由三段次级走势构成。在上述固定原子合同中，第三组只有这三个材料，不能由它们得到所需的本级中枢。即使额外赋予前两组真实完成见证，第三组的几何障碍仍存在。

因此，本例排除的是上述固定构造，不是 [33 课](../原文/chzhshch-108-plus/108/0469-486e105c010008x4-033.md)及 [59 课](../原文/chzhshch-108-plus/108/0552-486e105c01000b52-059.md)的九段升级结论。三组范围包络的交集 `[20,60]` 也不能证明三个合法高级材料存在；不得恢复已撤回的包络材料或“专用组合波动”。

### 2.3 方向补全与局部读法的边界

可以在九项前增加向下进入候选 `e:120→0`。若另有充分依据授予从120开始的向下整体／过程资格，q1—q3 的上—下—上就可以满足该方向的内部形成角色。e 不计入原九项。

这说明只增加形成方向过滤不足以一般排除本例；它没有直接证明整体起点或完整归属。后文给 e 提供笔层候选，仍不以此授 F2 整体资格。

另外，q4—q6 与 q5—q7 的几何核心均为 `[45,50]`。若某个窗口另有合法生成及来源资格，q8 的向下离开与 q9 的严格下方首返会破坏这一局部核；q9 同时仍触及原核 `[40,60]`。所以，原核无第三类点不等于所有有依据的局部读法均无第三类点。这个事实不能自动生成这些局部窗口，也不能直接完成包含它们的整体。

### 3.3 q8 的第二特征序列

q8 向下，第一特征序列为 `[46.5,70]、[20,30]、[25,42]`。它具有严格底分型，但第一、第二元素间有缺口。

从候选低点20开始的向上序列，其反向笔给出：

| 第二序列位置 | 来源笔 | 区间 |
| --- | --- | --- |
| 左元素 | q9 第二笔30→25 | [25,30] |
| 中元素 | q10 第一笔42→28 | [28,42] |
| 右元素 | q10 第三笔35→22 | [22,35] |

中元素的低点满足 `28>25` 且 `28>22`，高点满足 `42>30` 且 `42>35`，构成严格顶分型。相邻元素没有包含关系，按78课要求进行普通包含处理不会消除这个顶。

67课明确说明，第二序列的分型不用再递归区分第一、第二种情况，也不要求封闭第一序列的旧缺口。因此42仍低于46.5，不构成单独的拒绝理由。

q10 的末端特意选22：q10 的三笔构造期间均未跌破 q8 的候选低点20，从而没有触发78课“尚未形成第二特征序列分型又直接创新低”的失效条件。此处不依赖“同一根笔既形成第二分型又突破旧极值时谁先处理”的实现争议。

由此，按67课第二种情形，纸面上可以确认 q8 在20结束。同一组 `[25,30]、[28,42]、[22,35]` 又是 q9 的第一特征序列；它的前两项重叠于 `[28,30]`，所以也提供 q9 在42结束的无缺口确认。

### 3.4 首次可知事件

令 `kappa(i,3)` 表示 qi 第三笔满足本库上游确认合同、成为确认笔的事件，而不是该笔端点对应 Bar 的时间。它还可能依赖右侧分型、包含处理等事实；本文没有为这些事件虚构实际日期。

尤其，当前 F1 以随后有效反向笔冻结当前笔，q10 的第三笔 `35→22` 不能仅凭22已出现就算作确认笔。实际 Bar 化仍需提供其右侧成笔及分型证据；只在22右侧补足局部分型，不当然等于该笔已经冻结。

| 结果 | 纸面上全部列明证据齐备的事件 |
| --- | --- |
| e 在0结束 | kappa(1,3) |
| q1—q7 分别结束 | kappa(2,3)—kappa(8,3) |
| q8 第一分型候选 | kappa(9,3) |
| q8 第二分型确认，终点仍为20 | kappa(10,3) |
| q9 无缺口确认，终点仍为42 | kappa(10,3) |

如果这份笔序列由真实输入产生且没有其他先行候选阻断，q8、q9 可以在同一个确认笔事件交付。q8／q9 的终点事件早于它们的确认事件。执行器需按实际确认事件记录 `known_at`，不能把纸面端点时间作为当时已知事实，也不能把 q10 的确认用途误记为原九项的材料覆盖。

上述事件是本构造在列明前提下的纸面依赖结果；并非已经取得实际 F1 最早发布时刻的测量证据。当前 [Rust L0 合同](../rust-l0/README.md)还规定了候选先后、确认笔冻结、真实笔破坏、原始全区间和启动边界，实际回放须逐项检查这些条件。

## 4. 38课“双六项”的原始候选与审查历史

### 4.1 候选原意

[38 课](../原文/chzhshch-108-plus/108/0485-486e105c010009be-038.md)正文确实在固定同级分解语境中说明，次级材料延伸到六段，可以作为两个本级盘整的连接；[42 课](../原文/chzhshch-108-plus/108/0497-486e105c010009l8-042.md)作者署名回复 `2007-04-04 16:34:54` 也再次说明这一点。不能把它们降格成没有结构含义的交易标签。

曾提出以下候选：先在同一固定 H 分解 D 中，利用 q1—q6 的六项延伸获得 P1、P2；再在 P2 已获证的位置上，对 q4—q9 的六项延伸应用同一规则，复用同一个 P2，得到 P3；最后让三个真实固定 H 分段进入已确认的 S06 成枢入口。候选只打算授固定 H 分段权限，不授普通整体完成。

候选仍须证明：这里六段所指的精确覆盖；第二个窗口在同一 D 中的授权；P2 的分段身份和权限相同；全部材料与角色相容；S06 需要的进入、起点与方向合同均满足。几何上还要求第二组六项相对于其自己的核成立；原42结尾的反例不满足这一点。

### 4.2 前轮裁定与后续修正

此前曾以“第二个尾P可能仍在发展”及42课的后续趋势情形，反驳“双六项”的三段完成输入。重新审查后，这个否定理由不足，不能继续写成已证反例。

38／42课直接使用两个盘整类型连接的表述，而18课的盘整定义以完成走势为前提，不能没有论证就把第二个P一律降格成开放尾部。42课也确实说N个本级不延伸中枢可以保留为一个本级趋势，但该命题不能自动取消另一个已获证固定分解中的切点。[43课](../原文/chzhshch-108-plus/108/0499-486e105c010009mm-043.md)明确展示高级组合与固定同级分解可以采用不同分界。

曾提出的抽象续接是：将原例的最终42改为48后，继续 `48→0→10→−10→5→−20`。q7—q9 的核为 `[45,48]`；右侧还可出现较低核。这个计算没有证明新趋势读法与候选固定分解D采用同一起点、方向和材料归属；因此它不能作为同一D中既有分段失效的已证反例。该续接也没有作 Bar／L0 回放。

前轮撤回了当时尚无充分推导的“双六项已是有限 U09 充分构造”主张，并未宣称“双六项不可能”。当时的具体义务是：从38／42的原文适用语境取得第一份联合分段；证明第二组六项可以从同一D已确立的位置再应用，而非另开一种不相容分解；绑定中间P的同一分段身份；说明P在高层承担方向角色与其自身中枢形成方向之间的合同；最后满足S06全部进入、来源和完成条件。

后续第6节用具名 D 政策、精确下级来源、36课上下文替换和分开的方向端口补齐了一个有限生产域，独立范围审查已接受该域。第7节以三个六项窗口给出正构造。原 q1—q9 的固定分组仍失败，也没有证明所有九段都落入此域。固定三项封装的撤回继续有效；有限 F6-D 只能从获准的六项关系生产两段，不能从任意三项直接授予完成。

## 5. 原文正例能直接提供哪些证据

### 5.1 57课：指定组合和精确核心保留

### 6.4 时间、存储和有限生成

对同一个实际输出绑定 x，最早事件保存为：

`earliest_known(x) = min_{完整相容证明 p} max_{p 中必要依赖 d} known(d)`。

共享 P2 获得第二证明时，不能把原最早时间覆盖成第二窗口时刻，也不能先分别取不相容依赖的最小值再求最大值。D、起点、下级来源或转换证据后来才到达时，按同绑定齐备事件发布，不回写为当时已经可知。

## 9. 有限构造不能覆盖的情况

### 9.1 原九项固定窗口仍然失败

第2节原 q1—q9 不能直接按固定 `3+3+3` 生产三个高级材料。第7节通过已给出的前缀及合法 D 上下文改变覆盖，未证明任意输入都有这样的前缀、D根及六项延伸关系。不能把新增正构造缩写成“九项统一向左移动一项”。

### 9.2 左移后的第一个六项窗口也可能失去延伸资格

取 `e:70→0`，随后九项端点为：

`0→100→40→90→75→80→50→60→20→45`。

原 q1—q3 核为 `[40,90]`；q5、q7、q9均触原核，相关原核离开／首返没有严格破坏。原 q7—q9 三交仍为空，因为最后高点45低于 q7 起点50。

左移后的首三项 `(e,q1,q2)` 核却为 `[40,70]`。q3从40上离到90，紧邻 q4的完整回拉范围 `[75,90]` 严格高于70，构成该核的严格三类点。因此 `e…q5` 不是 F6-D 的六项延伸窗口。原核延伸不能替代新窗口的延伸审核。

### 9.3 第一左移窗口成功不保证第二窗口成功

取 `e:120→0`，随后九项端点为：

`0→100→40→90→70→80→50→60→20→45`。

原核仍为 `[40,90]`，原奇数 Z 材料触核，原 q7—q9 交集为空。左移第一窗 `e…q5` 的首核 `[40,100]` 可以延伸；但第二窗 `q3…q8` 的首核为 `[70,80]`。q6从80下离到50，紧邻 q7首返范围 `[50,60]` 严格低于70，已破坏这个局部核，不能调用本次通过的 F6-D 延伸分支。

该例左移后的三组几何核分别为 `[40,100]`、`[70,80]`、`[50,60]`，都非空。这反而说明“各组三交非空”不替代六项联合分段的业务前提。

本节以上两个例子首先是抽象材料层的条件反例，不作为九段原文定理的反例。第10节单独补强第9.3节的第二例：给出明确 Bar 输入、当前 F1 的纸面接口证明及明示 ordinary／D 资格；第9.2节第一例没有因此获得同样证书。严格破坏后两个局部核是否可另走扩张构造，是另一项研究；本次 F6-D 不包含该分支，不以45课关于P加P的必要描述反推它已经充分成立。

### 10.2 五笔构造引理与精确表示域

给定严格交替的宏段 S→E，每段幅度大于 `2δ`。向上宏段取五筆端点：

`S → S+3δ/4 → S+δ/4 → E−δ/2 → E−δ → E`。

向下宏段取镜像：

`S → S−3δ/4 → S−δ/4 → E+δ/2 → E+δ → E`。

在实数算术中，每行首三笔有严格公共重叠，第三笔突破第一笔的末端；五笔方向交替，全部价格位于 [min(S,E),max(S,E)]，因此没有用内部额外极值扩大宏段全范围。用于本项目 f64 时，必须另外要求所有构造节点和插值节点均可精确表示、计算不溢出且严格不等式不被舍入抹去；这不是对任意有限 f64 端点的无条件构造。本节使用有限二进制分数，逐个值满足该要求，不授权 epsilon 容差比较。

以下证明向上宏段，向下由符号镜像得到。令相邻下段终点为 E′，取四个反向笔区间：

| 元素 | 所属笔 | 区间 |
| --- | --- | --- |
| U | 当前宏段第2笔 | [S+δ/4,S+3δ/4] |
| V | 当前宏段第4笔 | [E−δ,E−δ/2] |
| W | 下一宏段第1笔 | [E−3δ/4,E] |
| X | 下一宏段第3笔 | [E′+δ/2,E−δ/4] |

U、V、W的高低点均依次严格上移，彼此没有包含，不构成提前的顶分型。V、W、X构成严格顶分型：W的高低点都高于V和X，V与W交集为 `[E−3δ/4,E−δ/2]`，不是缺口；W与X也交叠而无包含。下一段首三笔公共交集为 `[E−3δ/4,E−δ/4]`，X的低点严格低于W的低点，满足实际破坏及方向消歧所需的突破。下一段内部没有高于E的新高。向下宏段相应得到严格底分型，V／W交集为 `[E+δ/2,E+3δ/4]`。

必须另外检查当前 [segment.rs](../rust-l0/src/f1/segment.rs) 的较早候选优先处理：当前宏段第4笔到来时，U／V会产生较早的 probe；第5笔到达真正宏端点E时，向上有 `E>V.high`、向下有 `E<V.low`，该 probe 被严格新极值取消。此时尚无足够第二序列形成更早确认，不能越过取消检查而保留旧切点。随后V／W才成为目标候选，X在下一段第3笔到齐时提供无缺口分型及 actual_break。这个明确取消过程与U／V／W单调共同排除提前三笔结束及旧候选阻挡；不是只看最终三元组后宣称五笔可用。

### 10.4 274-Bar输入公式及叶层边界

对上表连续50笔及最后4笔，取 `ε=1/128`；每笔a→b、`s=sign(b−a)`仍用六节点公式：

`a，a+sε，a+2sε，b−2sε，b−sε，b`。

共享端点只留一次。首端点120之前加119.9921875；最后30.125之后加30.1171875、30.109375。总笔数54，节点数 `2+54×5+2=274`。每个节点作为 `open=high=low=close` 的闭合1秒Bar，slot及known_at按第8.1节的安全UTC时间规则；本版本追加事件仍从1计。

最小笔幅1/16大于4ε=1/32，故笔内严格单调；相邻点Bar不同且无包含。原笔转折中心为 `1+5j`，相邻中心距5；ε邻域不越过另一笔端点，满足当前 [stroke.rs](../rust-l0/src/f1/stroke.rs) 的严格三K条件。分型右邻冻结与反向笔冻结规则同第8.2节。所有值均为可精确表示的有限二进制分数。
