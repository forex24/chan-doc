# F2原文规则闭合路线图

日期：2026-10-08。版本：计划v1。范围：32项闭合目标，26条原文业务规则及6条工程合同。

## 一、计数与效力

本路线图规定本次可信F2设计的交付边界，不声称缠论原文恰好只有32条定理，也不声称这是数学上的唯一最小规则集。R01—R32是交付任务编号，不是市场对象、运行时类型或旧项目规则的改名。

**固定计划：业务规则26条＋工程合同6条＝32项。** 最后的整体一致性、原文场景覆盖和独立设计评审是总验收，不再包装成新增规则。正文现有48章只是资料组织，其中包含重复论证、原例、状态说明和未决讨论，不能按章数计算闭合数。

本轮只制定清单，不增加闭合数量。按本计划初始化：R04有完整的限定输入域论证，记为“论证闭合、独立复核另记”；其余31项未按本计划完成整条闭合登记。它们大多已有材料或充分子域，不是要求把此前工作全部重做。独立复核、原图核验、原始数据验收、仓库发布分别登记，不与论证闭合混成一个勾。

只有作者正文、可确认作者署名答复和明确修订承担业务论证。工程部分从已明确的业务读写需求推导，不能反过来规定原文必然怎样分解。旧代码、旧类型、旧规则编号及旧人工行情不作为证明前提。先设计，整体通过前不写F2源码、测试或演示；最终使用Vec和稳定下标，不引入对象键／执行键／全局哈希去重，不截断合法解释。

## 二、一条规则怎样算闭合

每一条必须交付同一份可核查合同：

1. **确切命题与输入域。** 对象、观察方法、实际级别、组成、起终位置及完成依据明确；输入不能包含换名后的目标结论。
2. **正面输出与分支。** 规定产生哪个实际对象／关系、精确边界和核心；覆盖本条输入域中的成立、确定不成立、尚缺输入、输入不一致及域外情形。域外不等于行情非法。
3. **证明与依据。** 原文结论、推导、工程选择、未证假设分开。充分规则证明充分性；声称充要的证明两个方向。输出若有赖一个未证明的本条内部转换，不能结项。
4. **确认时序与多义性。** 给历史位置、证据齐备事件、合法重组后的变化及与其他读法的关系。确认材料不自动进入被确认对象的覆盖。
5. **边界核验。** 给原文对应与最小正反情形，逐项核材料角色；不能只重述原文结果或验证一组数字。原图或实际数据未取得时如实注明，其缺失是否阻碍本条证明须具体判断。

只写接口、增加反例、说明必要条件、修辞更名、整理表格、重复镜像，不新增闭合计数。辅助引理归属其主规则。若原文明确只支持有限规则，可以在事先登记的输入域内闭合；不得临时把“一般盘整结束”缩成一个特例后仍给整个R13打勾。

允许分条证明：例如R04以前一级已完成材料为真实输入，不必在同一次交付里重证所有低层规则。但全系统验收时，每种必需输入必须能由底层事实或已闭合规则产生，不能留下循环等待或没有生产来源的“完成／合法／相容”标签。

## 五、依赖与研究顺序

### 5.1 依赖图必须保留的主链

- 原文输入及真实窗口 → 中枢形成／延伸／破坏 → 相应走势完成和后继。
- 合法重组与具体完成 → 九段实际中间级构件 → 精确高核 → 高级续接。
- 已明确业务读集 → 相容支持与时间 → 共享计算及业务规模 → 存储与执行合同。

这些是研究依赖，不是禁止级别下降的流水线。具体证明可以从独立高层结构取得低层重分结果；不能出现“本次待证高核生产自己的构件”的证明环。递归依赖须注明对象、级别和良基，不以画一张有向图就宣称无环。

### 5.2 固定下一项及核心优先级

**下一轮只处理R06：离开、首次返回与三类点。** 目标不是再证明严格范围分离，而是把原文的形成角色、首次性、54／61实际材料对应和等号边界统一成可判定合同。只完成一个严格子域而内部对应仍未解决，R06不结项。

核心研究优先队列：

`R06 → R16 → R13 → R14 → R15 → R17 → R18 → R19 → R20 → R21 → R22 → R23 → R24`。

这是选题优先级，不是假称未闭合前置已经成立。必要前置若阻碍本条实际证明，先明确缺哪一项、为何必须调整；不能暗中跳去一条容易的范围恒等式并把原条算作完成。

其余业务项R01／R02／R03／R05／R07／R08／R09／R10／R11／R12／R25／R26按上述核心链需要接入，已有推导尽量复用。工程研究在业务读集稳定到足以证明时接入，不以工程优化先限制允许的走势解释。

### 5.3 每轮固定回报格式

`本轮：Rxx（名称）｜状态：论证闭合或仍未闭合｜累计：k/32`。

随后只交代该条输入、分支与输出、证明、原例及反例边界、历史位置和确认时间、文档及评审状态。可修正其他既有错误，但修订不额外增加闭合数量。目标是一轮闭合一项；若仍有实质证明缺口，必须保留未闭合并继续当前任务，不能为满足数字虚报。
