## 2. 规则输入：真实波动，不是待决离开或任意范围包络

先取向上情形。在同一已核验解释I及其具体有序来源中：

1. B、C是真实、连续的两个H级中枢，C在B之后且不是另一解释的共享窗口；三项材料的完成、形成角色、所属关系及核心均已确定。B/C独立前后关系不能只由几何判断。B的完成已独立获证；本稿不讨论尚未结束的B。
2. 两个固定核心满足`ZD_C > ZG_B`。本文只覆盖该分离方向及其镜像，不处理核心重合、向反方向新生等其他情况。
3. B拥有非空有限实际有效Z集合Z_B；C截至当前材料前缀拥有非空有限实际有效Z集合Z_C。每项Z有真实材料引用、全范围[d,g]及归属，且与所属固定核相交。至少包含各自实际形成Z，之后仅加入已经获准吸收的Z。
4. 形成角色、连接角色、暂存离开、确认足迹分开。当前主设计§5.4.1规定暂存离开未被接纳时不进外围；本稿沿用这个归属合同，不以价格已经经过某处就提前将暂存项加入Z_C。后来回核实际允许补入时，以那时的资格事件加入。
5. Z集合只在保留同一形成窗口、同一核心和同一源读法的续接中增加。输入修订或合法重组另立对应，不能把更换窗口或删除角色当作此规则的普通延伸。

令`GG_B=max(g_b)`、`DD_B=min(d_b)`，C同理。这里是20课所定义有效Z的指标，不是整个证明树、全部接收Bar或所有离开材料的包络。

## 3. 可构造的双材料相交见证

**数学推导。** 在§2条件下：

`DD_C <= GG_B` 当且仅当存在 `b∈Z_B、c∈Z_C`，使`[d_b,g_b]∩[d_c,g_c]`非空。

从外围条件构造见证，不需枚举所有组合：取达到`GG_B`的实际b、达到`DD_C`的实际c。集合有限，所以两项存在。由于它们分别触及本核：

- `d_b <= ZG_B < ZD_C <= g_c`；
- `d_c = DD_C <= GG_B = g_b`。

两个交叉不等式足以证明区间相交。反向也直接成立：任意相交对满足`DD_C <= d_c <= g_b <= GG_B`。

因此，这里的外围相交不是凭空填满两个矩形得到的假象，可以落实到两条真实、已获归属的波动。**这两个Z仍是H−1材料，不是三个完整H走势，更不是一个H+1精确中枢。** 它们的交集只是一份外围接触见证，不能直接用作高级ZD/ZG。

下降镜像：`ZG_C < ZD_B`，取实现`DD_B`的b与实现`GG_C`的c。`GG_C >= DD_B`时，`d_c <= ZG_C < ZD_B <= g_b`且`d_b <= g_c`，同样给出相交对。

## 4. R20-W：相交已经发生，不必等后枢结束才成立

**原文结合推导。** §2前提成立且§3给出实际相交对后，第20课相应分支的材料依据已经齐备：在指定I中，新同级中枢与前枢的相关波动发生重叠。C的三项已形成是必要门；C所属整体完成、C的未来严格首返完成则不参加这份正相交证明。

输出限定为该实际B/C来源下的外围接触及20课高级结构关系，称R20-W。不创建虚构的高一级材料或精确核心，不反授B/C所在普通整体的完成，不宣称所有其他合法解释都有相同中心。已经被严格上移H趋势假设排除的这一B/C组合，不能仅凭核心仍然上移继续作为该假设的正证。

**续接保持证明。** 一旦相交对b/c成立，今后在同一I内、保持原核心且不撤销该对归属的合法续接，只会增加有效Z。原b/c仍在集合中，其固定真实范围仍相交；因此该正相交事实不可能由随后多接几项变成不相交。证明不依赖C最终在哪里结束，也不依赖最终最大最小值。

反面不对称：当前`DD_C > GG_B`只说明尚未有相交对。C后续接纳新的有效Z可以使DD_C下降，所以不能据此发表“这个C永不与B重叠”。这不是数值误差或计算性能问题，而是两种市场结论需要不同证据。

## 5. 与36课多义性的相容条件，以及R43的强化提案

36课“两中枢完全走出”的措辞不能省略。本稿的解释是：开放C仍允许改变组合，因此不能把一份当前分组的外围关系无条件强加给所有未来读法；但20课明确给出的完成前相交，又不能被改写为C一定结束后才有意义。故本稿只对**保留同一实际形成与Z归属的I**输出关系。

若后来依法将旧Z转入连接段，或将C改成另一起点的C′，新解释J不自动继承旧相交；它也没有让旧I原有的两条波动变得不相交。新旧结构各按自己的来源判定。这里不证明I一定永远是当前活动主解释，也不要求全部解释采用同一分界。

### 5.1 R43-W：候选强化，只去掉C完成门

在上一轮R43-D的§4.1、§4.1.1全部前提上，仅将“C已完成中枢、最终外围已固定”替换为：C已经真实形成；R20-W的相交见证在同一I及指定D/I_D映射中成立。其他前提原样保留：

- 左X至e的获准起点、恰有两个不延伸且同向分离的A/B、无遗漏同解释高级归属；
- 实际较小级别背驰点e及该范围内的H非背驰分类，不能由缺证或单一MACD值代替；
- C是该语境下独立生产的真实后继，不能依赖本次X的完成输出；
- D的实际根或已完成前缀末端s、原位置j与已选择I_D；连续完整H−1材料精确覆盖X至e，e是该I_D真实边界，不拆L0；
- A/B全部形成角色、有效Z、外围、无延伸与左类型在该映射中正面保持；不是“没发现冲突”；
- 新C及接触对与上述左证据共同相容。新解释若改变C或该相交对的归属，必须重新核验，不借旧结论。

**待复核的规则强化：** 第43课已经给出了相交分支的固定H切点e；§3—4又证明这一分支可在C仍开放时具有完整、不会被同源追加撤销的依据。所以，在全部前提齐备时，于D位置j生产X至e的完整FixedT，不再统一等待C完成。

这不是从几何单独推出完成：完成授权仍来自43课该语境的分解结论。也不是取消D/I_D映射或恢复普通完成自动上流；ordinary完成、C所属走势完成以及高级精确核心均不是本条输出。

R20-W的双材料相交证明，可以独立于R43-W成立。R43-W还需确认36／43课在上述固定来源域中确实允许此时作最终固定分段，而非只留下候选。若独立复核找到原文所要求、当前缺失的更强终止前提，应撤回R43-W强化，保留R20-W与旧R43-D，不得把数学相交定理冒充该业务桥梁的证明。

## 6. 具体材料：形成时可相交，暂不相交则有两种后续

沿用R43归纳步的已声明输入域：每项是真实完成H−1走势，表列全范围暂等于端点区间；所有左趋势、动力学、实际D/I_D资格另有独立依据。不是Bar/F1或完整动力学复现。

完整前缀为`0→10→6→9→7→20→15→22→16→30`。A形成于`10→6→9→7`，B形成于`20→15→22→16`，B核心[16,20]、有效Z外围[15,22]；e为最后30。后继C形成于`30→24→28→z`，其首段同时是B上离开后的严格首返，故B的完成独立于C的完成。

| z | C三项形成后的核心／外围 | 实际接触对 | 只用已成立输入的结论 |
| --- | --- | --- | --- |
| 18 | [24,28]／[18,30] | B的22→16=[16,22]；C的28→18=[18,28] | 相交[18,22]；R20-W已具见证，C尚未完成 |
| 22 | [24,28]／[22,30] | [16,22]与[22,28] | 相切22已成立；不需等C的后续离开／首返 |
| 23 | [24,28]／[23,30] | 此时无相交对 | 只知道当前尚未相交，不给永久分离 |

前两项没有把C第三条形成腿兼作形成后的离开；它本来就是已完成的合法形成Z，其全部真实区间进入初始外围。R43-W若最终获准，可在该形成事件及其他资格都齐备时确定e；旧R43-D还会等待未来的C完成依据。

### 6.1 同一z=23前缀，后续A保持分离

追加`23→40、40→35`。前项为C上离开，后项是紧邻严格首返，35>28。两者不加入旧C有效外围，C以外围[23,30]完成。该B/C关系没有相交，R20-W不触发；不会由R43-W在e完成。

### 6.2 同一z=23前缀，后续B在C仍开放时取得接触

另一个后续追加`23→27、27→21、21→26`：

1. 23→27是触核的反向连接，端点在核内，不扩大有效Z外围。
2. 27→21虽经过核心，但按当前局部合同先是待确认的下离开，暂不加入有效Z。此时不能仅凭21<22提前使用它的相交资格。
3. 紧邻21→26回到核心，且端点26在核内，不构成新离开。原27→21按它原有的形成位置被实际接纳为有效Z，C恢复开放，外围变为[21,30]。
4. B的[16,22]与新接纳Z的[21,27]相交于[21,22]。R20-W此时成立，而C没有取得任何严格首返完成。

这个例子既证明“未相交”不能提前固定，也检验“市场经过了21”与“27→21获得当前C的有效Z归属”不能混用。接触的资格获知最早为第3步相关证据齐备事件，而不是第2步端点21出现时。

### 6.3 首次事件

例如e的小背驰在事件9已证，B在10完成，C三项及z=18在12形成，D/I_D及左分类亦已在12之前成立。R20-W在12成立；R43-W强化若获准，其本份FixedT证据也可在12成立，而不是必须等待后续C在14完成。D/I_D在16才获证时仍不早于16。所有数字只是条件事件表，未运行F1。

历史分界始终是e，接触发生位置、C形成位置、C的未来确认端点不能替代e。多份充分依据保同一绑定后取最早，不将各解释的最早边际拼接。

## 7. 递归与多义性的决策影响

1. **拆开正反分支的必要门。** 新枢未结束，不意味着一切结构关系都只能待定；但当前外围分离也不意味着未来永久分离。C完成不应无条件成为所有关系消费者的统一门。
2. **从真实波动生产高级关系。** 两条已获归属的Z就能见证20课的外围接触；几何指标反查到实际材料，而不靠猜测全部未来。
3. **保留解释差异，不混用材料。** 同源追加保持接触；合法重新分配可能改变另一个读法的接触关系。两者不是矛盾，也不是全局删除旧解释的许可。
4. **完成规则仍有独立业务依据。** 只有另外满足43课及D/I_D全前提，才讨论固定分段；R20-W本身不完成任何走势。由此所得固定材料参与39/40成枢仍检查真实角色，不从高级关系反向完成自身构成材料。

U09的九段构造、一般完整c、ordinary P结束和全部合法重组未由本稿解决。尤其不能将两个接触Z的区间交集登记为高级精确中枢；本稿没有恢复已撤回的三包络算法，也没有要求九段等待第十项。
