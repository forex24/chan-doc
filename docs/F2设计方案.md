## 1. 固定语义与输入合同

### 1.1 三种事实，不能排成“完成权限等级”

| 实际事实 | 明确含义 | 禁止自动推断 |
| --- | --- | --- |
| 中枢及结构关系 | 指定形成窗口、核心、延伸、严格破坏或高级结构关系成立 | 包含它的普通走势完成；中枢本身变成完成走势 |
| `FixedPComplete(D)` / `FixedTComplete(D)` | 指定D及实际来源中的H级完成分段，端点和组成已获证 | 所有ordinary消费者通用；完整c；任意上层/另一D可直接使用 |
| 指定S的ordinary完成 | 指定来源、级别、起点、组成、分类和完成依据联合成立 | 其他同端点S也完成；任意交易信号已成立 |

固定完成不是“半成品”，ordinary完成也不是万能最高权限。哪一种完成能够被读取，由下述具体规则决定。**固定P不必先ordinary完成才能使用S06；局部核却不能只因有三项组成就被称为固定P。** 不设全局`Qualified`、`TailClosure`、`OwnershipRelease`或“NoPendingAbsorption”门。

### 1.2 输入及坐标

L0是现有F1交付的已确认最低层材料，具有实际方向和最低层完成意义；不等于没有方向的区间，也不授任何祖先起点或完成。读取扁平`LowestMovement`、有限f64价格、UTC及正TimeDelta；按输入账本追加序号分配稳定下标。旧MovementKey、level_ordinal、composition、direct_materials不恢复。

实际起终点、完整范围、形成核心、有效Z外围、组成材料、确认材料、测量区间分开。L0完整范围取实际端点时间之间原始Bar的闭区间极值；高层范围取合法组成的实际全范围，不用仅端点区间替代。确认用的右侧材料不自动并入左对象组成。事件位置、Bar位置、UTC、同事件材料截面分别保存。

价格按原有限f64严格比较，不量化、不加epsilon；数值相等含正负零相等。相切按本项目严格分离口径处理，不冒称原文不存在等号解释空间。

## 2. 每条规则的统一执行合同

一个规则实例必须有：具名生成位置、实际输入对象、需要共同成立的来源/角色绑定、冻结截面、结论和实际证据。输入不是几个没有身份的价格范围。

| 判断结果 | 应执行的动作 |
| --- | --- |
| 充分前提已联合成立 | 在该生成位置的已有结果槽发布或补支持；不重复建立同一事实 |
| 已有具体反证 | 拒绝该实例，保留反证及其对象/截面；不否定别的合法实例 |
| 某项已有生产规则的证据尚未到达 | 订阅该具名缺项；不当作几何失败，不提前移动搜索位置 |
| 当前没有实现该业务结论的充分规则 | 明示规则未覆盖及所欠结论；不伪装为普通等待、不补材料，不影响独立规则 |

“未覆盖”不是市场走势非法；发现别的合法来源可建立新的具名实例。新证据只补原命题真正依赖的事实，不以换名修复已有反证。历史事实与当前活动职责分开。

## 3. 中枢形成、延伸、破坏和重组

### 3.1 R4及三项形成：先有授权位置，再算交集

**输入：** 真实观察边界或其他规则已经给出的起点；同一实际有序来源中的三份连续、同级且对本消费者完成的材料m0/m1/m2；对应形成角色。材料级别h，目标核级别h+1。相邻实际末端与起点相接，来源须联合成立；不是只比较价格相等。

若相邻两项都不是P，实际方向须反向；有P时不能仅以净方向相同而拒绝，但仍需实际组合角色。指定向上S内部成枢要求下/上/下，向下镜像；这种归属须在发布S内部核之前证明。独立R4局部成枢不等待未知整体root，也不能反授该root。

**触发与输出：** 三项各有完整范围Rj=[lj,uj]。有 `ZD=max(l0,l1,l2) <= ZG=min(u0,u1,u2)` 时，发布本窗口的中枢和固定核心[ZD,ZG]。没有三项完成或角色依据时不发布。成枢不完成父走势。

完整范围交集不无条件简化为第一/第三项交集；只有另证二者交集包含于中间项范围时才可简化。来源见原文18/20、24课署名答复和技术基线§3.4。

### 3.2 五个生成入口及游标动作

记W(s)=m[s..s+3)，下标是该实际来源的原位置，不是全局对象下标。

| 入口 | 唯一初次请求 | 三项已齐但几何为空 | 成功后的职责 |
| --- | --- | --- | --- |
| 观察根首窗 | W(0) | 拒绝本窗，不任意右移重设root | 局部核；无普通完成 |
| 一项进入兄弟 | W(1)，m0为真实唯一左邻进入 | 拒绝本窗 | 另一合法读法；保留原合法读法 |
| 普通后枢 | 旧核由首返m[r]严格完成，从W(r)开始 | 单向s←s+1；缺角色不能按此推进 | 采用第一次成立目标，停止本搜索 |
| 完成枢共享 | 最后有效Z z、离开d、紧邻首返r，三者恰连续 | 拒绝本次，不向右补考 | 共享形成材料的局部读法，不冒充独立普通前后关系 |

晚首枢搜索的扩大入口、任意回核后右移，以及一般54/99重组，不因本表自动获批。

### 3.3 延伸：核心不动，外围按真实Z归属更新

**输入：** 真实C、固定核心K、材料原形成/连接位置、合法后续来源。

**触发：** 新材料按当前阶段真正被接纳到旧C；其中只有形成方向的有效Z且触K，才参与外围。

**输出：** 原C核心不变；Z外围按有效Z范围更新DD/GG，另保存全部合法覆盖、lastZ及接纳时刻。不为每个延伸前缀创建新C。

待首返的离开材料暂不并入外围。回核后获准接纳时，按该材料原位置入账，不按当下游标的位置入账。连接材料计覆盖，不自行扩Z外围。相同核心和外围不意味着相同来源或相同lastZ。原文20课；逐阶段动作见技术基线§5.4.1。

### 3.4 离开和紧邻首返：不以“全在核外”代替实际角色

设K=[ZD,ZG]。向上离开d须是上向非P或对本规则适用的完成P，满足 `end(d)>ZG`，并且 `start(d)<=ZG` 或前一真实材料触核。向下镜像。d必须位于本核形成材料之后，第三形成项不兼任自己的形成后离开。

紧邻下一份完整材料r才是本次首返检查对象。不可跳过它，等待后面更合意的返回。

| d/r类型 | 本规则可用性 |
| --- | --- |
| 非P＋非P | r与实际离开侧反向；L0采用同样的反向基元规则 |
| 非P＋P | 可以，但全范围及来源仍须核验 |
| P＋非P | r逆d的实际离开侧，不逆P的净位移 |
| P＋P | 当前普通严格破坏通道未获批；不全局禁止两P其他合法组合，也不跳过r |

向上离开后 `low(R(r))>ZG`，向下离开后 `high(R(r))<ZD`，类型/角色先通过，才发布严格破坏和相应严格第三类点关系。相等为相切，不发严格第三类点。**输出只完成C，不自动完成包含C的P或T。**

r触核时，本次严格分离不成立；再独立检查r是否构成新的离开，同侧/反侧都检查。若r自身重新离开，只接纳原d的适用覆盖，冻结r，不把r提前扩入旧外围。完整动作表仍按技术基线§5.4.1，不能简化为“回核即全部吸收”。

### 3.5 R20前后关系：外围接触不是高级精确核心

**输入：** 具有实际独立前后关系的同级A/C、连接和来源依据；不得仅因时间先后或来自同一报价源就配成一对。对该关系使用真实有效Z外围。

向上核心分离且 `ZD_C>ZG_A`、`DD_C<=GG_A`，或向下镜像 `ZG_C<ZD_A`、`GG_C>=DD_A`，给出对应高级结构关系及实际双Z接触见证。仅核心分离不能确认趋势；外围严格分离的趋势几何分别为 `DD_C>GG_A` 或 `GG_C<DD_A`，整体趋势分类还需其余结构资格。

两个共享同一Z的读法不能仅靠外围相交补出独立前后关系。低级外围交集不能当高级固定核心。旧C完成后价格回到K，发布回归/扩展关系，不复活旧C的完成前活动状态。原文20课及技术基线§5.4.2。

## 4. 固定分解及有限递归生产

### 4.1 F6-D：精确六项联合生产两个固定P

**输入：** 获准D、H、原相位、38课分解政策和实际下级I_D。入口只能为D获准起点、既有D分段起点，或已完成D前缀末端与下一实际下级材料相接的位置。六项u1…u6均是同一I_D中真实完成H−1材料，连续、不拆、不重复分配；D名字本身不能替代这些证据。

**触发：** u1/u2/u3在本位置具有FixedFormation38及首核；后三项按实际延伸/离开/首返规则延续首核，六项截面内没有先行严格破坏；u4/u5/u6另有同D的FixedFormation38及非空核。全部条件在同一D/I_D/位置/角色绑定内成立。

**输出：** 联合产生 `P_left=(u1,u2,u3)`、`P_right=(u4,u5,u6)` 两份 `FixedPComplete(D)`。边界3/3来自“恰六项、不拆、不重用的两P连接”加最低组成要求，不来自“三项成枢即完成”。范围按真实组成计算。右P不额外等待自己未出现的第七项首返。

**失败：** 拒绝这份六项证书；不取消其他合法完成规则，不新设任意后缀root。缺证不等于失败。完整定义见[九段核查§6](F2九段构造核查.md#6-有限生产合同-f6-d)。

### 4.2 F6共享尾：复用中段，不复制或延长它

第一F6已产生P1/P2后，P2实际起点拥有下一精确六项请求。展开P2的同I_D三项组成，接三项新的真实材料；第二窗口独立通过F6后，左结果引用原P2，右结果产生P3。不能只凭相同价格或端点认同P2，不能用第一窗口成功替代第二次核验。

P2原组成、真实末端、D位置和首次时间保留；后到证明只补支持。共享尾失败，不否定已完成前缀末端的另一个获准F6请求。来源见九段核查§6.3—6.4及原文36/38/39。

### 4.3 PR21精确价格子域：可作F6算术判据，不可作全F2替代

限H=1、原生交替L0且每项真实full_range等于端点区间，六项端点x0…x6、首核[L,U]非空，非价格前提仍逐项取得。下/上/下开头的F6价格门等价于：

`x4>=L && x5<=U && x6>=L`。

上/下/上镜像为 `x4<=U && x5>=L && x6<=U`。失败各有实际Z离核或离开/首返反证。对保持同一首核延伸九项的额外子域，两次相邻共享尾F6成功等价于九项存在共同价；共同价绝不是所有九段升级的必要条件。详见[PR21](评审记录/2026-10-07-双F6精确域与参数修订.md)。

### 4.4 S06：固定完成材料可以直接参与高一级成枢

**输入：** 获准同一D及原位置i，实际四个完成H分段Ai…Ai+3，进入及RoleIn39方向依据、连续来源和各项分段证明。保留原位置和相位，不对后缀重新编号。

### 4.5 九段升级：结构结论必须保留，构造缺口必须公开

**输入：** 同一实际解释的首三项成枢及后六项合法延伸，完成、方向角色、离开/紧邻首返、同向Z触核均有真实审计。九根Bar、九个候选或“没有完成记录”不满足此输入。

**设计执行要求：** 适用九段事实已成立而本规则库不能交付精确构件时，登记U09的具体未覆盖结论；不得改成“继续原级直到普通完成/第十项/第十二项”，也不得创建虚构材料填洞。该规则给结构关系，不伪称给了尚未构造的高级精确核或通用递归算法。

已证明双F6和S06只覆盖有限域。数量3^n、三包络交集、专用组合波动、隐藏拆L0都不作为替代producer。

## 6. 多义性、来源转换与首次可知时间

### 6.1 转换是实际源关系，不是解释名字相同

指定消费者逐项核验：输入版本和原子身份；起终位置及连续覆盖；级别/分解政策；具体组成和分界；P/T或指定有向过程；形成/离开/首返角色；目标窗口及仍影响后续的相关变量ρ。转换可以重分配已有子材料，但必须由具名重组规则证明新分界和完成含义。

同D名、同Bar范围、相同端点、核心或全范围都不是转换证明；反之，也没有规则只因早期解释名字不同，就永久禁止两个独立完成区间合法重组。不能要求一个任意全局历史标签作为所有规则的共同输入。

已成立高级核不全局停止其他分解。只有某条具体规则证明某实际绑定的活动职责应交接/终止时，才结束那个职责。历史完成事实、冻结问题及其他独立合法读法保留。已经有支持的同一命题不因无关候选出现而撤销。

PR22/R45仍待证的转换不进入本版生产规则；其晚根关联与相位反证不能被当作新ordinary完成器。

### 6.2 联合时间：先同绑定合取，再在完整证明之间取最早

对事实F及其完整相容证明集合P(F)：

`known(F)=min_{p∈P(F)} max_{d∈deps(p)} known(d)`。

没有完整证明时不赋成立时间。每个max只取同一输入日志中的知识事件号；不同来源材料截面不max，分别保留其实际引用和源对应。晚到root/映射/角色参加该证明的max，不回填成市场端点或第三材料结束时刻。

I有P@1、Q@10，J有P@9、Q@2：同绑定P∧Q的时间分别10/9，公共存在结果最早9；只适用I的后续仍读10，不能借9，更不能合成2。一个结果只保存全局最早时间而删除其他仍会影响消费者的完整支持，不合格。

### 6.3 R+T的可执行共享接口

业务生成位置拥有结果槽；实际连续片段已有窗口引用；实际C/固定D/冻结问题拥有具名职责。新增证明沿已有引用补支持。共同后继材料N及角色到达时，由已有局部数值状态G的该转移槽执行一次，结果先挂接再通知；各实际来源关系再联合授权，不能从纯数值结果反授权限。

保留与消费者未来行为有关的ρ，不把每份证明节点下标放入G。首次物理汇合沿实际owned末端L0/原子导出目录和已存在Vec引用查找，不扫描全部历史状态；目录比较、绑定构造/匹配和真实输出成本显式另计。具体目录、字段与阶段的充分性按技术基线§5.3—5.4及支持接口§14—15，不用“DAG固定元数”代替规模证明。

R份只是同一实际绑定的证据包装，且共同T步不读取这些差异时，包装R份＋后续T步各保存/执行一份，得到该部分O(R+T)。真实不同绑定M、映射成本B、每绑定输出等另计；不能宣称整个F2对N线性或已解决全部组合爆炸。

### 6.4 R20单调首次接触消费者的具体共享

限前枢A已经完成且有效Z外围冻结、后枢C保持同一形成/归属；独立前后关系已获证；C的后续Z接纳不依赖左关系残余选择。向上时每个前枢门槛g=GG_A冻结，C只保存初始有效Z低点及逐次新低记录 `(事件,C截面,低值,真实Z证据)`。非新低不可能首次命中`DD_C<=g`。向下镜像保存新高。

关系资格联合时刻a_r与共同首次接触时刻κ(g)给 `τ_r=max(a_r,κ(g))`，只max事件号。迟到关系二分记录，未命中稳定引用放C本地Vec堆；每条真实关系最多首次命中一次。空间O(T+M+E)，计入B、二分和堆的成本；M=1且E=R的纯包装场景满足R+T。任意Z配对、改组C或相关接纳选择不属于该子域。详见[PR17](评审记录/2026-10-07-R20首次接触与共同后续.md)。

## 7. 递归生成与事务顺序

新增完整材料只通知实际依赖它的窗口/职责，不枚举全部三元组。单一来源的普通后枢游标每次确定几何失败只前移一位；精确F6、共享、S06在各自位置只持一个结果/等待槽。不同合法D、源映射和语义不同角色的总数量仍需证明，不能用单位置有限性冒充全局界。

按真实依赖进行单事件内归约：接收材料→适用形成/延伸/破坏→具名完成/重组→高一级形成→合法后继请求，直到没有新的受支持结论。它不是所有对象必须经过的单线生命周期；联合完成规则允许一次给多个结果，但不能以自己正在证明的高核作输入补自己的构件。

同事件多材料按原delta顺序保留截面，不以事件末尾的C状态覆盖更早六项证明。新增订阅立即追赶已有事实，不等下一事件。历史版本追加引用，不每事件复制全部Vec。

## 8. 数值、覆盖与失败恢复

MACD采用现行数值合同而非旧整数Q：原close不量化；按规定递推表达式各自精确求值后一次舍入为binary64、最近偶数，保留次正规数；首close初始化快/慢，其他正零。柱按2^-1074单位精确解码为整数，正负面积分别精确累计与比较；分块前缀加至多两个边缘块，不使用简单f64前缀相减。34个u64肢的范围界以独立Bar计数不超过u64为前提。公式、舍入、覆盖及金标以[数值合同](F2MACD数值合同.md)为不可省略正文。

正式Bar与校验冻结close入口分开，后者不推进F1/L0。缺覆盖返回缺证，不返回0或“不背驰”。数值准确不生产完整c、趋势资格或普通完成。

真实输入/数值失败时，事务恢复质量门、F1 morphology、MACD、F2及所有消费位置，保留UTC与原输入事件编号；解除原因后按原失败事件序号重试。不能只回滚F2而继续使用已推进的F1。业务缺证/规则未覆盖与运行错误分别记录，不以数值异常或缺证制造走势终止。
