## 1. 先裁定一般命题，再裁定R43的有限实例

必须区分两个命题：

- G：任何H级左走势能够被确定完成，必须已经有从其终点开始、独立完成的H级右走势。
- W：在43课规定的小背驰、后继同级中枢重合、指定同级分解语境中，可以由已经成立的右部结构确定历史分界，不必等待右部整个走势完成。

**本轮判断：G应排除；W须由43课的具体规则证明，不能仅凭G不成立或仅凭外围相交的单调性宣布成立。** 前一轮P1指出了真实右来源的重要性，这部分保留；“独立右完成”是否必要则必须另有来源，不由审查标签决定。

### 1.2 G会导致有限在线前缀没有任何完成项

以下是工程逻辑反证，不是新增缠论公理。固定一个有限、已接收前缀，假定每条走势拥有正的来源长度。如果每个已知完成H走势L都必须以**同一来源链中右邻的已知完成H走势R**为必要前提，则end(R)>end(L)。对R又应用G，会严格向右继续。

有限前缀不可能容纳无限严格右移链。因此，若G对所有完成生产者无例外成立，有限前缀内不能有任何完成H走势。这与36／39／59的已完成前缀直接矛盾。允许某个特殊生产者不依赖完整右走势，就已经放弃G的普遍性。

反证没有否认某条具体完成规则可以需要完整右走势；也不把“右走势将来终要完成”的存在性当作当前已经知道它完成。

## 2. 连接级别约束不能混入另一种关系

[18课](../原文/chzhshch-108-plus/108/0419-486e105c010007t8-018.md)中枢定理一明确限定：**在趋势中，连接两个同级中枢的走势低于该中枢级别，可以恰为次级，也可以更低。** 正文先说不一定恰为次级，再允许更低级与跳空，故不能把“次级别以下”读成严格小于次级别。

若H为中枢级别，用递归序号表达，真实连接走势b满足level(b)<H；恰为H−1允许，并不要求level(b)<H−1。这与中枢形成三项各自恰为H−1是不同的关系。

| 关系 | 级别规则 | 不能偷换 |
| --- | --- | --- |
| 三项形成H中枢 | 三个连续、完成的次级走势及实际形成角色 | 任意更低级连接不能直接顶替一条次级形成材料 |
| 趋势中的A—b—B连接 | A/B同H；b低于H，可为更低级；缺口按其另有的来源表达 | 不能强迫每个b都先生成H−1中枢；不能拿同H走势当作无中枢连接 |
| 36课混级分解的重新归一 | 原文允许用真实下级分解和结合律重组 | 不是每个低级连接都可凭空包装成H−1走势 |
| 左H完整分段后接右H未完成尾 | 是走势类型分解的前缀／尾部关系 | 不是两个H中枢之间的b；不能误用level(b)<H去禁止它 |

这条区分对R43有实际作用：右部已经有一个H中枢C，不等于可以把其整体当作低于H的连接继续塞进原X；但C也不是一条完成的H走势。必须通过对应分解规则决定边界，而不是靠改对象名称解决。

## 3. 43课实际授权的是哪一条分界

[43课正文](../原文/chzhshch-108-plus/108/0499-486e105c010009mm-043.md)先讨论小级别背驰不足以立即结束本级走势，再分类：原H向上过程a+A+b+B+c之后产生同H中枢C。B/C不重叠时原H过程延续；重合时可采用a+A+b+(B+c+C)，若作H同级分解，分解点就是所述小级别背驰点e。

这里的a+A+b+(B+c+C)与(a+A+b+B+c)+C使用不同组合边界。C是中枢符号，不是在右侧偷偷给出一个CompleteMovement(C)。不能把原文公式读成先有一个完整右H走势，才出现分界授权。

本轮所作的业务推导是：**43课重合分支给出的是真实同级分界，不只是“以后可以去研究的某个坐标”。** 当这个分支的全部适用事实已经成立，并且指定D确实采用保持这些角色的实际分解时，可以确定前缀中以e结束的那个完整H分段。右侧仍可作为未完成尾部存在，符合§1的分解形式。

这一步的依据是43课的分解结论。§1只说明这种“左完整／右开放”输出没有被一般分解语义禁止；它本身不替任何e生产分界。

## 4. 对R43-W的有限推导链

本节保留[旧R43-D](F2递归规则研究-43课同级分界.md)§4.1.1的全部正面D/I_D映射条件，并采用[开放后枢稿](F2递归规则研究-开放后枢相交见证.md)§5.1紧接e的实际右来源条件。不是任意开放C触碰任何旧B都能结束左段。

### 4.1 全部前提必须实际成立

1. 指定I、H、左起点s及X至e的实际来源已确定。左区间有恰好A/B两个不延伸、同向严格外围分离的H中枢；形成、连接、所有适用Z及没有遗漏的同解释高级归属已经核验。不把当前没有记录更高级结构当作反证。
2. e确实是原文43所述c中的实际较小级别背驰点，且本次属于原H非背驰的第二种情形。所需c角色、动力学与作用域必须有实质依据，不能把比较窗口、一个上行箭头或缺少H背驰证据换成这个前提。本稿不解决U02的c生产。
3. D的根或已完成前缀末端、原位置j、所选I_D明确。其连续完整H−1材料u_p…u_q精确覆盖X至e，u_p.begin=s、u_q.end=e；逐项保持A/B及左类型。e属于该I_D的真实边界，不切开L0，不借另一I_D的结构，不改已确认D前缀。
4. 右C由同一I_D的紧邻三项u_(q+1)…u_(q+3)独立形成，u_(q+1).begin=e。与原I的C形成及随后Z归属逐项对应，B/C具有真实独立前后关系。B的中枢完成已有独立依据；C形成不得依赖本次左FixedT。
5. C核心与B核心按原方向严格分离；在同一业务绑定内已有属于B/C的实际有效Z相交对。暂存离开、另一个C′、未获归属的低级波动和证明范围不能替代该对。用的是第20课的关系及既有R20-W，而非高级精确核心。

这些是具体归纳步的前提，不保证一个任意数值序列能同时满足它们。尤其旧z=18算例只说明几何成立，没有自行证明第2项完整语境。该限制不会因自动审查无问题而消失。

### 4.2 从前提到结果，逐步说明依赖

| 步骤 | 所得事实及依据 | 不使用的前提 |
| --- | --- | --- |
| A | C已经形成，真实相交对存在。来源是右三项完成与有效Z归属 | 不需要C的未来离开／首返；不需要右H走势完成 |
| B | 在保留该来源的读法中，B/C符合20课相应重叠关系，不能仍按外围严格分离趋势处理 | 不计算或假造B+c+C的高级精确核心 |
| C | 由43课第二情形的重合分支，指定同级分界为e；由正面D/I_D映射，分界作用于D的原位置j | 不从“未发现冲突”推出合法分解；不任取一个小背驰点 |
| D | 该分界左侧拥有既定s…e范围，且目标D保留完整两枢趋势结构，故获得D中的完整H趋势分段 | 不要求原I的无条件ordinary完成；不要求右尾完整 |
| E | 右侧保留实际已知来源及开放状态；该左材料仅在另行满足39／40原位置、方向和三项条件时参与上一级成枢 | 不把C自身提交为完成走势；不因有一个新左材料就自动升层 |

本稿据此主张：**对该同源有限域，R43-W可作为D内的完成分段生产者，C完成与右H走势完成均不应再是统一等待门。** 完成来自步骤C的原文分界授权，而非步骤A的区间几何。当前提交此主张作独立审查；合入前不更改现行生产域。

这也没有假定“任一后续都不能改分解”来证明自己。原文36允许改变组合；变更形成窗口、角色或I_D的目标J应有自己的分界判断，不能反过来抹去原D的来源事实，也不能直接继承原D的完成。39课保持的是同一分解的已确定前缀，不是所有分解之间的共同切点。

### 4.3 对36课措辞的正面核对

36课有“两中枢完全走出”的说法；20课又明确讨论后中枢完成前出现相关接触。不能删去任一句。本稿只用以下作用域：两个中枢的形成三项均已完成；C虽未结束，其已经获证的实际Z接触不因同源追加消失；其他重新组合仍分别保留。

这一限定足以排除“把当前分组的相交强加给所有未来解释”的推论，却不自行证明步骤C。步骤C仍直接诉诸43课给定分解语境的重合分支。若证明该处“分界”只在另一个尚未满足的终止条件后才有效，就必须指出该条件的原文、或保持4.1全部前提而分界e失效的合法续接。本稿不以“文中没写”代替正面分界依据。

## 5. 三个事件层次，不互相替代

设e的小背驰在E1获证，C的形成与实际接触在E2获证，目标D及其全部同源角色在E3齐备，则本规则的一份完整证明不早于max(E1,E2,E3及其他必要事件)。

- e是实际历史切点，不因E2较晚就将左段延伸到C形成终点。
- C的形成终点不是左切点，更不是右H完成端点。
- 某个后来的C严格首返只提供另一条证据，不回填最早分界，也不因存在更晚充分证明抹掉已经成立的较早证明。

若源前提后来才到，发布就在后来；这不是在历史图上看到结果后提前知道它。若曾修改输入或数值政策，则按数据版本重放，不能把重算结果当原知识。

## 6. 什么是真反例，什么只是再次要求同一个门

| 提出的情况 | 对本有限规则的影响 |
| --- | --- |
| C三项已成枢、相交已见证，但右H没有完成证书 | 这正是要裁定的域，本身不是反例；需说明4.2步骤C为什么不能适用 |
| D选中的下级项跨e，只有另一I_D才留住A/B | 违反4.1.3；不授左完成，须另有合法重组 |
| 只知道e后某处有C，中间来源／角色未明 | 违反4.1.4；不能确定应在e切 |
| e是任意更早的内部小转折，不是43语境中的那个c转折 | 违反4.1.2；不能一律从此处造左段 |
| 27→21尚是暂存离开，还未成为C的有效Z | 违反4.1.5；接触资格尚未产生 |
| C只形成一个中枢，但尚无足够右部依据判定任何给定规则的分界 | 一般情况下仍是候选；本规则依靠的是额外满足的43完整语境，不把所有成枢变完成 |
| 某个合法续接保留同D/I_D、c角色、实际e和B/C归属，但原文要求D越过e继续同一左段 | 这是有效反例，应给出具体材料和原文；将直接否定本稿R43-W推导 |

相交对不可能因只增加有效Z而消失，这是数学事实；最终同级分界能否成立是业务事实。两者分别证明，不用第一项代替第二项。

## 7. 本轮裁定范围与不可扩大的结论

本轮提出两项应分别签收的结论：

1. G不是普遍完成规则。36／39／59给出原文依据，有限前缀严格右移反证解释其递归后果。
2. 在4.1列明的R43同源有限域，依据43实际分界而非仅依据几何，主张可以产D中左FixedT；其右侧仍可开放。此项需审查4.2的具体推导，不因第一项成立就自动成立。

没有解决通用九段构造、一般ordinary盘整完成、完整c启动或全部合法D选择；没有恢复专用组合波动、三包络高级核心、任意三项封装或任意L0拆分。R43-D仍是有更多右侧证据的充分子域，不因研究更早门而被抹去。

本稿对连接级别的确认只恢复18课原范围：趋势的中枢连接低于本级、可以恰为次级；不许可级别乱接或所有更低级材料直接成枢。数据结构与共享服从这项规则，不反过来要求所有关系使用同一个固定级别流。
