# F18-D：真实固定分解首三项的高一级成枢

日期：2026-10-05。提案基线：PR #2的`7876b56b753628cee3647fbd115dd124d4ce57b0`。**这是业务生产规则的有限推导，待独立复审；不是新的主方案，也不宣布整体F2通过。** 约束仍以[主设计](../F2设计方案.md)为准，不写或运行F2源码、测试、演示。

## 1. 待裁决的限制

当前F6-D输出的是指定固定H分解D中的真实完成盘整；S06已经允许这类材料在39／40课的指定四项语境下形成高一级中枢。尚须区分：

- “不存在任意FixedCompleted→OrdinaryCompleted转换”；
- “固定D首三个已完成H走势，也一律要等第四项或另一个进入段才允许观察H+1中枢”。

前一句继续保留；后一句不是18课成枢定义的前提，不能只因当前S06使用四项窗口就自动附加给所有形成入口。本稿给一个直接以真实完成材料为前提的首三项生产域，不新增任意后缀、任意进入长度或三项完成封装。

业务推导是将已获证的三个FixedPComplete(D)作为18课定义的实际输入，在同一D来源解释下建立局部H+1中心。它不是因为工程枚举值叫Complete就放行：必须实际引用F6-D等已经证明的分段见证。固定D材料的完整类型与来源保留；仅新增该首三项局部成枢的使用权限，不把它们改成普通完成材料。

## 3. 精确生产域

一次F18-D请求由已经获准的固定D根位置拥有。D至少固定：H、实际分析起点、38课分解政策、原位置方向定位、选定下级I_D及源材料对应。

只读取D首三个实际已完成H走势P0、P1、P2，不对任意后缀重新建立根，不改变D原序号。每项须满足：

1. 有同D、同实际位置的真实FixedCompleted证书；本稿正例只使用已审F6-D生产的P，不使用普通T转投、未完成尾部或仅价格包络。
2. 各项级别都是H；实际owned来源顺序连接，目标内不重复分配；确认依据仍可共享。
3. D公开的真实位置／方向关系给出上—下—上或下—上—下的形成序列；不是从P的净位移自行生成角色，不因零位移分叉。
4. 三项完整价格范围按其实际组成取值，闭区间公共交集非空。
5. 完成、D位置、来源和角色在同一完整业务绑定下相容，不将不同D、不同I_D或不同分段的边际最早证据拼接。

P0起点已知且属于D，不等于一个H+1普通整体的起点已获证。本消费者仅创建该D来源上的局部高一级中枢；不同时声明其属于某个已指定的有向H+1整体S。以后若要将它归入S，仍核验S的root、方向、材料归属和相应转换，不能以本条先成枢再补造错误的指定归属。

## 4. 构造与结果

先读取三项已有完成槽及Qualified支持，再联合D成员、连续性和形成角色。通过后计算：

`ZD=max(P0.low,P1.low,P2.low)`，

`ZG=min(P0.high,P1.high,P2.high)`。

当ZD≤ZG时，18课定义的三个实际完成输入均已齐备。输出CenterUnder(D,H+1,P0,P1,P2)及其精确核心、形成来源和见证；其formation_owned是三个真实owned的有序连接，origin为P0.start。这里CenterUnder表示现有中心记录绑定D来源，不引入另一种“专用组合波动”。

该生产顺序中没有循环：下级真实完成与D准入→两次F6-D的固定H完成→本条高一级中心。H+1中心不回头给P0/P1/P2补完成。祖先普通root和普通完成也不是隐含输出。

原S06继续用于其有进入段及原Ai位置的四项情形；本条只取消把S06那组充分条件误当作D初始三项局部成枢的必要条件。它不推翻S06原角色要求，也不授权任意三项跨分解拼接。

## 5. 九条L0的具体正构造

这是冻结L0输入层的条件性纸面构造：同一实际I_D的九项均已由上游完成，其全范围确为端点区间，D准入和真实角色证据独立提供。**尚未为这个新增例子运行Bar／F1，也不借用已有249-Bar等同名运行收据。**

端点序列为：

`0→10→2→8→4→9→3→7→5→8`。

| 项 | 端点 | 实际全范围 |
| --- | --- | --- |
| u1 | 0→10 | [0,10] |
| u2 | 10→2 | [2,10] |
| u3 | 2→8 | [2,8] |
| u4 | 8→4 | [4,8] |
| u5 | 4→9 | [4,9] |
| u6 | 9→3 | [3,9] |
| u7 | 3→7 | [3,7] |
| u8 | 7→5 | [5,7] |
| u9 | 5→8 | [5,8] |

W0为u1…u6：首核[2,8]，尾三项核[4,8]。u4仍在原核内；u5上离到9，紧邻u6返回最低3重新触核，没有严格破坏。首尾形成角色独立符合F6-D。因而W0实际生产：

- P0=(u1,u2,u3)，起终0→8，完整范围[0,10]；
- P1=(u4,u5,u6)，起终8→3，完整范围[3,9]。

W1在同D已有P1的真实起点展开u4…u9：首核[4,8]，尾三项核[5,7]。u7、u8、u9都与首核相交，其中u9结束在上界8，不构成严格离开／首返破坏。通过同D实际来源替换，W1复用同一P1，生产：

- P2=(u7,u8,u9)，起终3→8，完整范围[3,8]。

D的首三项P0/P1/P2在本例实际原位置上分别获上、下、上的外部形成角色。原始九项首核[2,8]的后续同向Z——u5、u7、u9也分别触核；但本条不使用“数量九”来补完成，而使用上面两份已经逐项通过的F6-D见证。

现在真实三个完成H材料的范围交集为：

`[0,10] ∩ [3,9] ∩ [3,8] = [3,8]`。

故本域中形成局部H+1中心，origin=0，formation_owned=u1…u9。没有第十项，没有额外前置A0，也没有把三个源包络先当作完成材料。中枢成立仍不完成包含它的H+1整体。

## 6. 首次事件与共同支持

设九项按实际输入日志依次获知事件E1…E9，D准入与所需来源／角色证据在对应生产事件前已齐备。这里只规定冻结L0接收事件，不冒称E_i等于原Bar端点时刻。

本证据链中W0在E6齐备，P0/P1最早可由该链获得FixedPComplete；W1在E9齐备，P1只新增另一份证明，P2由W1获证；F18-D在同一个E9闭包内形成[3,8]高核。已知前提支持的多个结论同事件成立是无循环合法推导，不因同事件而拒绝。

若D或角色证据晚到，取该实际完整见证全部依赖的最大事件。对同一目标多份充分证据取最早，不跨真实D绑定取min。已有其他生产者提前给某材料真实完成时，可以保留其较早支持；本表不声称枚举了所有其他充分通道。

D根位置拥有一个初始F18-D结果槽，指定三个真实分段位置分别订阅一次。P的纯证明包装变化不另建一个高核；实际分段／角色差异保留Qualified关系。此条每个获准D根最多一个初始请求，真实D总量、Γ和窗口查找仍另计。

## 7. 拒绝例与不能跨用的权限

| 情形 | 正确处置 |
| --- | --- |
| 只有三组重叠范围，没有真实FixedCompleted | 不产生高核；不能用本条反向补F6 |
| W0成功，W1未完成或严格破坏 | 等待真实生产者或记录规则缺口；不把P2按三项默认完成 |
| 274例第二左移F6被破坏 | 本条不能修复缺失的第三H1材料，U09该域继续开放 |
| 没有第四项进入A0，但本条D初始三项全部前提成立 | 可形成局部高核；不能仅因S06是四项窗口而拒绝 |
| 不是D首三项，任意后缀重编号为0/1/2 | 本入口拒绝；其他窗口须有自己的生成依据 |
| 后续要在B中用两个FixedP判严格破坏 | 本条没有授P＋P普通破坏权限；18课三种类型组合及该消费者真实来源仍须核验 |
| 后续要由B完成普通H+1走势 | 另读实际普通完成规则；局部中心存在不充分 |
| 后续更高D'要求另一种下级分解政策 | 先取得实际I_D'和政策相容来源，不能把当前D序列静默改称ordinary低级流 |
| 想把本条高核归入指定有向整体S | 先核S的形成归属与起点；不得仅凭数值或本地origin反授 |

本条只补一个真实的高一级成枢生产入口。它不证明所有九项都能用两次F6分段，不关闭一般G1、完整c或未知ordinary root，也不声明“所有固定H输出都可无条件普通递归”。
