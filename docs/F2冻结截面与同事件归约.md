## 1. 新问题：同事件不是同一个材料前缀

当前[F1PipelineDelta](../rust-l0/src/lowest.rs)以Vec发布本次确认的segments和lowest_movements；[贯通场景](F2贯通场景.md)也有q8、q9在同一事件确认的纸面例。主设计要求保留输入事件序号和实际消费位置，但“在边界开放”的谓词仍须指出到底是哪一种边界，不能只留下一个事件号。

设某实际解释中枢C的核为[2,8]。离开d为2→12，首返r为12→10、全范围[10,12]；完成、连续性、类型及角色作为本例明示前提。F1在事件E一次发布d、r：

| 截面 | 已按本解释消费的材料 | 局部状态 |
| --- | --- | --- |
| σ0 | 尚未消费d | Open |
| σd | 消费到d | WaitReturn(up)，尚未严格完成 |
| σr | 消费到r | Completed，由d/r确认 |

σ0可能早已在前一事件获知；新增σd和σr在E的全部相关输入／资格齐备且提交后才可对外发布，不能虚构E内部两次真实市场获知时间。但σd和σr是不同的有序材料截面。某冻结问题需要d边界时的状态，读取事件末尾最新C会错误读到σr；反之，拿σd当作事件提交后的当前活动状态，会漏掉真实完成。

这个例子只揭示接口不充分，不证明所有现有实现都必然犯错。它不依赖d/r在不同事件发布，也不修改严格首返业务定义。

## 2. 三个不能互代的坐标

| 名称 | 定义 | 禁止替代 |
| --- | --- | --- |
| 知识事件E | 必要输入／资格真正获准接收的日志位置 | 不能以历史UTC或材料端点时间代替 |
| 材料截面σ | 指定实际解释／来源映射在规定有序材料位置完成一次合法转移后的不可变投影 | 不能只用事件E、末价格或最新C下标表示 |
| 当前活动权 | 提交时，指定职责和实际绑定仍可消费哪个后继位置 | 历史Reach存在不等于现在还可推进 |

σ引用既有生产者的已执行转移／状态版本和实际角色关系。不是新的ObjectKey、执行键、全局逻辑时钟或私有历史编号；不必创造“事件E.1”的对外事件号。不同分解同样使用已有源映射和消费位置；全局第n条L0不天然等于每个高级消费者的第n项。

数值G即使可共享，也不独自构成σ。σ仍须绑定实际C、来源、已消费末项、累计覆盖及必要资格关系；它们可通过Reach和已有前缀引用保存，不复制整套历史。

## 3. 将三个谓词分开

### 3.1 PrefixState：关于给定材料前缀的状态

`PrefixState(C,σ,b)`说明实际绑定b在固定有序来源前缀σ下，按对应版本的局部规则得到的状态。

后续r可以为较早材料d的完成提供确认依据，但不能因为r在同事件已经可见，就偷偷将r当作σd内已消费材料。组成和确认足迹继续分开。σd可以是当前知识对过去材料前缀的合法投影，不声称它曾作为独立外部实时快照被发布。

若转移尚有缺资格、规则未覆盖或未解决首个输入，则保存相应状态，不从“未看到Completed”推导Open。固定C与解释下的局部状态也不证明所有其他解释不存在高级中枢。

### 3.2 KnownBy：关于证据何时齐备

`KnownBy(F,b,E)`要求至少一份支持指定完整绑定b的充分证据，其全部必要事件不晚于E。它是额外的时间筛选，不由材料截面自动推出。

必须先在真实绑定内联合，再作截止筛选或等价的逐前提筛选，最后才消去获准的私有变量。不能把端口的全局最早标量和另一个绑定的角色相乘。

| 绑定 | P | Q | P∧Q | 在截止9以内 |
| --- | ---: | ---: | ---: | --- |
| I | 1 | 10 | 10 | 否 |
| J | 9 | 2 | 9 | 是 |

后续R只接受I时，不带截止的联合首次是10；若目标还要求KnownBy(…,9)，则该目标没有合格支持。事件10后来收到的真实新证据可以完成无截止的问题，不能让“9之前已经知道”的历史断言变真。

这不取消合法晚到补证。具体消费者必须声明哪些前提有知识截止，哪些只需支持原冻结对象、允许后来获知。不能给所有Local29前提一律加“冻结时已经知道”，从而拦掉既定的晚到root或来源证据；也不能给明确要求冻结前已具备的资格无依据取消截止。

### 3.3 ActiveAtCut与ActiveNow：推进权不是历史布尔值

处理d/r例时，σd之后的合法下一输入就是r；σr的完成关闭其后的原C延伸职责。如果在处理r之前先读取事件末尾的ActiveNow=false，就形成“必须先处理r才能知道关闭，却因关闭而禁止处理r”的倒置。

事件内每条转移依据其前驱截面的职责及指定下一输入许可。事件提交后的ActiveNow从已经核验的职责交接结果派生。二者引用同一实际来源链，但不是同一个时态查询。

冻结题读取规定的历史截面；退休只限制相应活动职责，不删历史证明。新解释的接收权必须有独立转换，不因同一价格或相同G自动继承。

## 4. 冻结记录具体保存什么

由具名问题生产者已有的冻结结果槽保存：

| 字段职责 | 最小实际内容 |
| --- | --- |
| 对象与范围 | 指定S/C、级别、root资格目标、实际owned／测量片段 |
| 冻结截面 | 既有转移输出σ引用、实际末项／消费位置及来源映射 |
| 冻结谓词 | PrefixState、结构分类、角色等具体所需命题，不用一个含糊open标志代替 |
| 时间政策 | 每个必要前提允许晚到或具有KnownBy截止；严格早于与不晚于须明确 |
| 支持 | 完整绑定b及尚相关变量、已得证明与准确缺项 |
| 后续职责 | 指定缺项订阅；完成结果槽或合法冲突结果槽 |

每次成功转移先挂接不可变数值输出及Reach动作，再推进活动游标。若该位置已有冻结题，就让它引用这个实际输出；不是在事件结束时从最新状态倒推。

后来才登记的题可以引用已保存的对应转移和支持视图。若根本没有保存足以恢复σ的资料，则须沿已有源链重建该局部投影并计费，或明确缺证；不能称作O(1)读取，也不能改用当前C凑答案。正常生产应在具名边界生成时保存结果槽，使晚到资格不需全历史重跑。

## 5. 同事件归约的有限顺序

以下是工程顺序，不新增市场事实：

1. 接收一个外部事件，按上游公布的有序增量登记真实材料和证据。批次是一个提交单元，材料位置仍逐项保存。
2. 已有局部消费者依指定来源的下一材料转移。前驱σ必须先存在；同事件多项沿真实顺序依次消费。未覆盖或固定重组请求不跳过首个待解输入。
3. 每个成功转移立即建立不可变截面及具名冻结结果槽，再排入由新增事实触发的完成、固定H、来源转换和高级消费者。
4. 对共享前提的消费者使用带完整绑定的联合；新订阅立即追赶。不同级别新交付仍在同一事件闭包中处理，不强行等下一Bar。
5. 真正的活动职责关闭／交接引用具体转移和目标绑定，不能靠队列先后把历史正事实清掉。外部当前状态只在闭包提交后公开。

同事件有一条升级证明和一条普通完成证明时，两条规则都须核验自己要求的截面、来源和权限。不能写一个无业务依据的全局“升级永远优先”或“完成永远优先”抹去合法结果。存在真实排他要求时，把它作为该绑定的明确前提／冲突规则保存。

需要“没有更高级归属”“没有其他完成依据”等否定命题的消费者，不得把当前工作队列暂空当作完备证明。它需要固定解释／区间与规则域的完备结构审计，或具体的正面充分见证；未覆盖规则域不因调度结束变得完备。不能只登记一个NoHigher布尔量就关闭U01或U09。

若某条规则为证明前提又依赖自身输出，应保留循环缺口，不因同事件闭包最终要结束就先补一项。当前开放规则尚未给出全部生成域及无环证明，本文不宣称整个F2固定点终止已证。

## 6. 一个安全的局部遗忘操作：新lastZ覆盖旧lastZ

共享数值G之后，实际lastZ可能仍在Reach中不同。设合法转移接收形成位置N，所有入域绑定已经分别通过Γ，动作将lastZ明确覆盖为N。设x保留目标后续仍读取的全部其他字段，旧lastZ为z：

`F_new(x,N) = min_z max(F_old(x,z), Γ(x,z,N), step_time)`。

这里的step_time只指该规则新增的真实必要证据事件，不是数值计算／物理分配的墙钟时刻；没有新的外部前提就不额外推迟业务时间。先联合Γ，后消去旧z；不得先对F_old全局取min。合法覆盖动作不等于所有源映射、root或C都相同，它们只要后续仍读取，就必须留在x中。

仅当后续可续职责不再读取旧z，才可投影它。已经冻结的旧问题如果需要旧z，继续引用F_old的σ及关系，不能转读F_new。新lastZ不能更换旧问题的“最后有效Z”见证。

对实际仍有关联的旧变量，这提供一个可验证的作用域结束点：不用将旧z永久携入所有后续状态，也不用删除旧证明。若某个未审查消费者以后还能通过另一角色读回旧z，则上述x不充分，投影不得启用。

本节只证明这个局部更新的正确代数，不声称所有业务历史都能在同一时刻遗忘。没有授权的一般转换、未知消费者和真实Γ匹配仍归D03/D04。

## 7. 空间与执行成本

设R份纯包装支持同一实际命题，T步有相同合法后续，F个真实具名冻结题。共享转移／支持视图各建一次，冻结题引用已有σ，因此该限定域的存储可为：

`O(R + T + F + 必需证据本体大小)`。

它不是每个冻结题复制R份历史或T步数组。旧σ通过前驱／动作引用保持可解析；这是持久引用，不是每事件复制全量快照。

时间须另外计入：首次目录查找、真实资格联合W_qual、截止查询、来源映射求值、历史局部重建和必需输出。若F个题各要求列举R个实际不同绑定，输出本身可达R×F；不得把它藏在一个共享引用后声称总成本线性。有限R+T不因本文被推广成全F2多项式。

在同一完整绑定、事件政策和字段读取条件下，纯包装不会创建新σ、新问题或重复订阅。新真实binding或新活动资格的变动须通知，不能为了省算漏掉。

## 8. 纸面验收项与审查范围

| 设计验收项 | 必须得到的结果 |
| --- | --- |
| d/r同事件 | σd待首返、σr完成可以同时作为E获知的不同前缀事实；最新状态不覆盖旧冻结 |
| I/J、截止9及仅I后继 | 无截止仅I为10；有截止9则无支持，不能借J的9 |
| root晚到且规则允许 | 支持原冻结对象、按实际到达事件完成，不回填；不错误添加全局截止 |
| 未解决前提 | 缺资格／Uncovered不等于Open；不跳首个输入 |
| lastZ覆盖 | 新职责读取N；旧冻结题仍读取旧z，不能反向授新旧角色 |
| 调度排列 | 在同一有序输入、实际绑定和已闭合有限规则域下，更换无依赖工作出队顺序，不改变截面事实和首次事件 |
| 提交失败 | 所有暂存σ、通知和结果随质量门/F1/MACD/F2共同回退，不留下已发布悬空下标 |
