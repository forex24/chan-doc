# F2原文重建计划

日期：2026-10-08。性质：依用户要求重新确定研究基线与交付顺序；不是新规则已经证明或设计已经通过。

## 一、研究基线重置

本轮起，研究问题改为：**不依赖旧项目，仅从作者原文，能否建立一套能够识别、解释并递归组合走势的规则？**

旧项目的代码、规则编号、接口、已通过审查和既有算例均不作论证前提。旧材料保留为历史资料；新规则独立建立之后，才将旧实现作为待检查的适配对象。不能为保持旧分层或让旧算例通过而解释原文，也不继续以固定六项分段作为整个递归体系的主干。

用户的工程约束仍保留：整体设计通过前不写F2源码、测试或演示；将来使用Vec和稳定下标，不以全局对象键、执行键或哈希去重解决组合数量；不靠截断合法解释控制规模。这些是交付约束，不是缠论定理的前提。

不预先认定旧项目所谓L0就等同于原文的最低走势类型；也不预先拆出“固定完成、普通完成、拥有权完成”等实体。先查原文中同一词在各语境下的对象、级别与作用，再决定是否确有必要作形式区分。

## 二、从原文确定的研究主轴

以下是已回到作者原站核对的出发点，不是旧项目结果的复述。

**1. 中枢与走势类型必须通过级别递归共同建立。** 第35课明确指出二者相互依存，并以最低级别及逐层定义消除循环。第17课也给出最低观察级别的处理；第63课进一步区分理论递归与实际图表观察。[17][35][63]

**2. 图表周期不是走势级别。** 第63课将图表比作观察工具，并说明可从选定基本图的分型、笔、线段建立最小中枢，再递归分析。新方案先采用这条实际图表研究路线，逐笔定义作为理论参照；两种口径的对应需要明示，不能将分钟标签直接当作结构证明。[35][63]

**3. 结构达到最低构成，不等于已经结束。** 第18课同时给出成枢与走势类型定义，并明确区分可以结束和实际结束。第45课用从买点开始的走势生长说明结构分支需要由后续走势确定。新方案必须一起研究形成、延伸与完成，而不是先制造一个通用完成开关。[18][45]

**4. 多义性属于研究对象，不是最后附加的实现异常。** 第36课要求在同一理论下保留不同解释，并允许按较低级别展开后重新组合。第38课的固定同级分解是一种选择，且不同层未必采用同样的分解规则。新方案先研究一般连接与重组，再研究这一特定方法的范围，不能把它反过来当作全部理论。[36][38]

**5. 范围、边界和观察方式不能混为一谈。** 第53课明确区分完成走势的实际起终点与内部高低点。第99课具体展示旧组合在后继中枢形成时的重分。新方案不以几个相同区间认定走势身份，也不把较高层旧括号一律锁死；任何重分仍须保持原文定义，不能任意切开已确认线段。[53][99]

**6. 原文中的修订必须进入定义。** 第67课明确用特征序列精确化此前线段破坏说法，并指定以后以该定义为基础。不能把不同阶段的说法机械拼成同时成立的一组公理，也不能仅因发表较晚就让整篇覆盖所有早期论述。[67]

## 三、先分清三类问题，不新增三层市场对象

| 问题 | 必须回答 | 不能用什么代替 |
| --- | --- | --- |
| 定义与存在 | 什么是某级别的中枢、走势类型及合法连接；定义为何不循环 | 旧类型名、接口字段、已有输出 |
| 形成与判定 | 在已列明前提下，怎样构造或确定一个具体结论 | 把待证结论换名写进前提 |
| 当下获知 | 到当前观察前缀，哪些结论已可确定，哪些仍允许继续发展 | 用事后全图答案回填过去 |

这只是论证问题的区分，不是新的Fact层、权限层或Boundary系统。第17、18、45课的当下性与第63课对存在性、实际分析的区分，是重新组织这些问题的依据。[17][18][45][63]

存在性命题不能自动变成常数时间在线算法；离线划分正确也不能自动证明其每个前缀的发布时间正确。这两点是工程推理要求，不冒充原文定理。

## 四、工作顺序与实际交付

只维护一份逐步扩充的原文规则主稿。主稿分为“原文命题与定义”“规则推导”“核验及未决项”，不再每次另建一套框架。下面是研究工作包，不是宣称市场按一条单向流水线运行。

### 工作包一：原文口径与递归基础

以17、18、35、63课为定义主线，核查62、65、67、71、77、78课对底层图形的定义和修订。

交付：原文术语表、修订关系、选定观察精度下的最低单位、线段与最小走势类型的对应，以及逐层定义的依赖说明。必须回答“线段为什么可以参与这里的最小中枢构造”，不能用“因为旧L0接口这样定义”回答。

通过条件：每个基本对象有原文定位；没有同级相互等待才能定义的循环；没有将所有连接强行视为恰好次级；逐笔理论口径与图表分析口径明确分开。尚未读取成功或尚未核查的课文，不登记为本轮已证。

### 工作包二：中枢生长与走势实际完成

以18、20、29、43、45、53课为主；补核27课及与盘整完成有关的可确认作者答复。

交付：中枢形成、维持、离开、返回、破坏，新同级中枢出现，趋势延伸，以及盘整/趋势结束的具体产生式。每条都写清目标对象、级别、材料、方向语境、必要条件与充分条件。

同时把背驰的结构定义、实际转折及辅助指标测量分开。不得把更小级别转折当父级必然完成；也不得因为未来仍可重组而删除原文已经给出的本级终止结论。[29][43]

通过条件：能逐项说明“中枢结束”“该走势类型结束”“另一分解下的边界”是否相同；不能仅用一个has_center或has_divergence给出完成。等号、首次返回、缺口及混级连接需根据原文逐项确定，不继承旧项目默认口径。

### 工作包三：连接、多义性与合法重组

以35、36、38、39、40、53、70、99课为主。

交付：原文允许的连接与重组规则，每次明确变换前后的实际走势、级别、组成、边界以及保持的性质。同级分解在此作为一种具体规则体系处理，而非预设所有层都使用的唯一算法。

先重建35课a+B1+B2+B3+b的边界组合、36课低层展开后重组、99课两种后继中枢组织方式，再处理更一般的变换。不把结合律理解成任意括号都自动获得任意级别或完成身份。[35][36][99]

通过条件：每个新组合都能由明确规则产生；不能仅写“有合法转换”却不交代转换；不以解释名字决定永远不能连接，也不因端点相同就准许连接。某种固定分解的唯一性与其他合法分析视角的存在不能相互混用。

### 工作包四：跨级构造与九段规则

以18、20、33、35、53课的定义和结构结论为基础，对照57、59、70、99课的作者实例和重组说明。

交付：从实际低级走势到较高级中枢的构造；九段命题的准确计数对象、适用语境、三个次级构件、边界来源、核心计算和当下确认条件。明确结论属于存在、具体构造还是某一种规范化解释。

九段问题与工作包二、三共同求解，不要求先完成全部普通走势算法才能研究九段；也不把尚未生产的高一级构件作为已给输入。原文前提确实满足时，不能因为现有算法无输出而延迟结论。

通过条件：至少把作者实例逐步重建到实际材料与边界，而非只抄最终区间；所有一般化须有推导。不以九项固定分组、三个范围包络、旧反例的预设原子封闭性代替证明；也不能无依据否定输入有效或任意拆已确认线段。

本轮只核对57/59正文中的陈述，尚未逐图重建，因此不把这些实例登记成已经复现。

### 工作包五：从规则到在线识别

只有已建立的原文语义与产生式进入这一阶段。

交付：每条规则的实际触发位置、必要证据、首次可知前缀、延后确认时怎样处理已有合法解释，以及规则之间的依赖。不要求当下总能给出唯一终局划分；第99课明示一般划分可能处于尚未确定的生长阶段。[99]

通过条件：同一观察前缀不使用未来材料；新增证据不混淆历史结构与当前解释；共享前的两份结论确实在后续所读语义上等价。证明有序推进不会跳过合法结果，而不是只写一个状态机。

### 工作包六：实现适配与规模

原文规则建立之后，才决定数据结构、调度、数值算法，以及能否复用旧实现。

交付：规则到Vec及稳定下标的对应，实际请求/绑定数量界，共同后续共享条件，数值精度及失败恢复合同。

通过条件：优化前后保留同一套已证明语义；成本按真实实例、匹配、证据和输出计，不按规则名称数量计。先判断哪些多义性确实改变结果，再研究如何紧凑表示；不能先承诺线性或多项式，再删除解释来满足承诺。

本工作包完成并通过整体设计评审后，才进入F2源码和测试。设计阶段可以列纸面验收场景及预期，不将其称为已经运行的业务验证。

## 五、每条规则的交付格式

| 栏目 | 必须提供的内容 |
| --- | --- |
| 原文依据 | 课号、正文段落或已核作者回复、原站地址；图例与正文分开 |
| 命题性质 | 定义、原文断言、充分条件、必要条件、等价条件、操作建议或实例，不混标 |
| 完整语境 | 对象、级别、分解方式、观察精度、材料顺序及边界 |
| 结论 | 具体产生或排除什么，不写泛化的“新边界/新权限”替代 |
| 推导 | 从前提到结论的步骤；未完成步骤保持明确缺口 |
| 当下性 | 哪份材料使结论首次可确定，事件位置与历史价格端点分开 |
| 核验 | 作者实例、最小正例、真正反例、等号及缺口等边界；测试设计不冒充证明 |

遇到原文不能唯一决定的问题，必须说明不确定的精确位置。继续核查相关正文和可确认答复；不能把某个工程选择默认为作者结论。作者明确修订优先按其实际范围处理；无法消解的差异并列保留，不为迎合旧算法强行统一。

## 六、首个里程碑

下一份实质交付固定为：**《原文定义、最低级别与递归基础》**，直接回答下列问题并给出产生式或明确的缺证位置，而非再次列框架：

1. 所选择的基本图及观察精度是什么？分型、笔、线段、最低级别中枢和最低走势类型之间各是什么关系？
2. 一个已经完成的低级走势如何成为高一级定义的材料？哪些连接可以低于次级，怎样重组为次级序列？
3. 中枢形成、允许走势结束、实际结束的命题各自是什么？从哪个原文条件得到，不得循环预设？
4. 同一段行情的不同分解保留什么、改变什么？哪些结论是所选分析视角的结论，而非所有解释共用的永久边界？

其中第1—2项提供底座，第3—4项决定下一批生长/完成/重组规则。作者九段实例保持跨级验收目标，不再让旧项目的某一个人工路径支配所有研究。新规则独立建立后，旧算例可以重新作为反向检查材料，但没有解释特权。

交付是否推进，以新增或确切修正了哪个命题为准；仅改术语、重画架构或再列一张覆盖表，不计作规则完成。
