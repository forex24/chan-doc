# 规02联查规05：UDU首枢与DUD调整形成的条件衔接

2026-10-09。沿用24条业务＋4项工程、分类验收和依赖驱动排程。主项规02；本轮关闭的是给定实际次级材料上的一条条件形成衔接，不是规02的全部来源问题。业务纸面4/24（01、03、04、09），工程0/4。E34和其他生产策略不变。

## 1. 本轮裁决与来源范围

第107课从反弹的UDU次级表达讨论中枢及后续三买、非背驰向上；正文没有列出替代首枢的DUD三项。第25课2007-01-23 22:11:56的署名答复，又明确以从高点开始的调整解释上涨中的成枢。因此，两处不能用“以后一定重组”这个未给材料的断言自动统一。[107][25答]

本轮给出一个实质性的条件连接：**在同一实际次级序列中，UDU形成之后的下一份已完成D触及原核，则后移一项得到的DUD三项必有公共区间。** 这是第18课的完成次级定义、第20课两类形成以及第36课按真实低级材料重新组合的限定推导；作者没有逐字写出本稿的通用公式。[18][20][36]

本结论不证明第107课所有情形都必然具备这份第四段D，也不证明第107课作者实际采用了这个改组。它使“可以怎样改、何时能改、改后保留什么”有了可以核查的材料与条件，而不是提前裁定唯一生产策略。

第45课从一买a开始允许前三份次级构成最弱结构，同时明确形成与实际结束不同。本稿不以缺少第四段为理由，撤销已在其原文观察中成立的三段形成；也不以三段形成反授本级走势完成。[45]

## 2. 真实输入与确定的材料位置

固定观察O、数据版本V及实际h级次级分解D。已有四份按原分解连续相接、独立完成的走势M0、M1、M2、M3，切点为q0<q1<q2<q3<q4，Mi覆盖[qi,q(i+1)]。已有原生方向为上、下、上、下；方向不能由本次将要形成的中枢反推，也不能用高级盘整的端点净差临时补出。

M0/M1/M2在所给反弹观察中已有原中枢C0的实际形成依据。M3是q3之后的下一份实际下行材料，不能从历史材料池挑一份价格合适的D来替换。四份完成及切点必须独立于待证新中枢，不能用C1已经存在证明M3完成。

读取各Mi的真实完整价格范围Ri=[li,ui]。它们包含各自实际起终价，但不要求实际端点是全段极值。[53]

本条确定地产生一个相邻调整窗口：

- 原形成窗口W0=(M0,M1,M2)，覆盖[q0,q3]，方向UDU；
- 新检查窗口W1=(M1,M2,M3)，覆盖[q1,q4]，方向DUD；
- 同一四项前缀的观察表达由(M0+M1+M2)+M3，改读为M0+(M1+M2+M3)。

括号只标明被本次观察选取的形成材料，不表示括号已经成为一个完成的高级走势。q0仍是原观察入口；M0转为新形成之前的材料，未从行情中删除。q1成为新形成起点，不自动成为整个高级走势起点。

这是对本份已知次级序列的局部形成输出，不宣称W1是所有合法分解的唯一首枢，也不把C0/C1计作同一趋势里前后两个独立核。两份窗口共用M1/M2，必须保留其重叠的实际来源。

## 3. 完整范围下的构造与证明

### 3.1 不需要端点极值假设的公式

令两份共用材料的公共范围为：

J=R1∩R2=[LJ,UJ]；LJ=max(l1,l2)，UJ=min(u1,u2)。

原C0已有形成依据，因此J非空。原核与新窗口核分别为：

K0=R0∩J=[L0,U0]；
L0=max(l0,l1,l2)，U0=min(u0,u1,u2)；

K1=J∩R3；
L1=max(l1,l2,l3)，U1=min(u1,u2,u3)。

若L1≤U1，按三份真实完成h级走势及本次DUD相邻角色，取得该形成表达的h+1级中枢，精确核心为[L1,U1]。若L1>U1，该窗口不成枢。单价位分支保留；这不处理全部三类点等号语义。[18][20]

### 3.2 触及原核为什么足以生成新调整核

假设R3∩K0非空。取其任一共同价格x。因为K0⊆R1∩R2，所以x同时属于R1、R2；又x∈R3。因此x∈R1∩R2∩R3=K1。

于是得到正面产生式：

真实UDU首枢＋实际下一完成D＋R3∩K0≠∅
⇒ W1中的DUD形成，且K1非空。

实际共同价格见证可以直接取p=max(L0,l3)，其上界检查为p≤min(U0,u3)。这不是输入“新窗口有效”，有效性由既有范围和实际材料推出。没有父走势完成、MACD、未来趋势或假定更高级核作为额外前提。

触旧核是这条衔接的充分条件，不是新三项成枢的一般必要条件。若R3只与J落在K0之外的部分相交，K1也可能非空，此时只能分别记录新形成，不能声称它触及旧核。完整分支使用3.1的充要式，不将充分条件反用。

### 3.3 精确记录新旧核的关系

集合恒等式为：

K0∩K1=(R0∩J)∩(J∩R3)=K0∩R3。

它同时给出新旧核是否相交及其精确共有价格，不把一个新包络当核心。

新旧价格核心相等，当且仅当L1=L0且U1=U0。形成方向、形成三项和时间覆盖仍然不同，因此价格核心相等也不证明原有全部来源身份、首次时间及下游关系可以不变地搬运。

两份上沿相等，当且仅当min(UJ,u3)=min(UJ,u0)。这项数值条件必须实际检查；在完整范围允许内部极值时，UDUD方向本身不能保证它。

## 4. 标准端点范围中的具体连接及失败

下面只是前述实际结构已经成立后的条件核算，不是从五个价格识别出四份完成走势。

设端点为p0→p1→p2→p3→p4，方向UDUD；本小节额外假定每份完整范围等于其端点区间。记H=min(p1,p3)，原核L0=max(p0,p2)，并已有L0≤H。

新核心为：

K1=[max(p2,p4),H]，非空当且仅当p4≤H。

证明：R1=[p2,p1]、R2=[p2,p3]、R3=[p4,p3]。因为p2<p1且p2<p3，所以取三交即得公式。

当p4≤H时，新旧上沿都为H；但下沿是否相同还须max(p2,p4)=max(p0,p2)。当p4>H时，新窗口为空；不能只把UDU标签改成DUD。

以0→10→4→12→p4为例：

| p4 | 原核K0 | 新窗口K1 | 实际结果 |
|---|---|---|---|
| 3 | [4,10] | [4,10] | 核心相同，形成证据和覆盖不同 |
| 6 | [4,10] | [6,10] | 有新调整形成，共有上沿但下沿改变 |
| 10 | [4,10] | {10} | 单价位调整核 |
| 11 | [4,10] | 空 | 这项后移构造失败 |

最后一行只否定这份后移三项，不能否定原107观察中的C0，不证明其他全部分解不存在。没有M3时也不是失败，而是尚无本构造所需的后继材料。

完整范围下，上沿并不必然相同。例如同样真实端点0→10→4→12→6，若已独立取得的范围为R0=[0,16]、R1=[4,15]、R2=[4,20]、R3=[6,14]，则K0=[4,15]、K1=[6,14]。每个范围包含各自端点，但新上沿14不同于15。该条件赋值只检验范围合同，不冒称是真实市场或F1复现。

## 5. 三买可以接到哪一步：门槛相同不运输全部证明

假定q4之后又独立取得实际次级向上离开d、其首次回试r，并且同一d/r在两份形成表达中的角色、级别和连续关系都已分别成立。它们不能从K1形成反造，也不能只因时间在核后就取得“离开/首次返回”身份。[20][53][61]

对严格离核子域，两个数值条件分别为low(r)>U0和low(r)>U1。若U0=U1，两者对同一r等价。因此，在两份完整结构依据齐备时，可保留各自来源下的同一三买位置end(r)，只共享这个价格比较。

例如p4=6的新旧核上沿都为10，已独立完成的d:6→20和r:20→15在两份来源中若均为所需离开与首返，则都满足15>10。r的完成及第一返回关系仍是实际输入；两个箭头的数字不代替这些结构依据。

若U0≠U1，应分别判断。上一节完整范围例中，假设某已取得返回的最低价为14.5，则它严格高于新上沿14，却不高于旧上沿15。这只给出两份价格判断的区别；没有实际d/r来源时不发布任何买点。

本次不要求两份来源的确认事件同时到达。对每份证明，最早可知取该份形成、级别、d/r、完成和数值证据齐备的最大事件；新形成的较晚确认不能借旧核的早时间。共享同一r的历史端点，不等于共享证明时间。

107课还要求相应的非背驰向上，不能仅凭两核共享三买上沿，就把完整107后续结论一并搬运。需要另核当前解释中实际比较对象、覆盖、级别和动力依据；某个辅助面积较大也不是完整非背驰证明。这里仅指出真实依赖，没有将规10改为统一前置门。[107]

## 6. 当前来源裁决：一个可执行连接，不是全域统一

现在已不必在两个过强说法之间二选一：

- “107首枢UDU有效，所以所有以后形成与用途都必须保留同一三份材料”没有由本构造证明；
- “后来上涨必取DUD，所以107首枢当时必定已被换掉”同样没有被证明。

可确认的是：UDU原形成与稍后的DUD调整形成，在本条实际条件成立时能够从同一有序材料中分别取得；两者的核心可能相同、部分相交，也可能新窗口根本不存在。它们的证据位置可以不同。第36课允许不同组合有不同具体意义，这使保留原形成与生成新形成不必等同于任意改写历史。[36]

这与107课的连续叙述相容，但还不是对该课所有情形的唯一解释。原文没有逐一给出本条M3、范围条件及其完成；本轮也没有证明这些条件在所有107式三买之前必然成立。第25课的调整要求保留，不能降格成“只谈第二中枢”；第107课的反弹首枢事实也不能仅因没有本构造就被删除。[25答][107]

高级盘整若尚未取得其在本序列中的实际上/下角色，停在该具体缺项。本条不定义通用盘整方向，不按端点净差或末内部单元补方向，亦不将缺角色当作原文永久禁止参与形成。

## 7. 完整分支、输入生产与下一工作

| 当前证据 | 本条动作 |
|---|---|
| 原C0来源、连续关系、四份完成或原生方向未齐 | 列出具体缺项，不先发C1再用它回填 |
| M3仍在生长 | 可以读当前范围，不将最终L1/U1、C1确认及q4提前发布 |
| 数值倒置、非有限、覆盖断裂或不含实际端点 | 报输入错误，不当作市场上的空窗口 |
| 实际四项齐备且L1<U1 | 产生该相邻DUD的正宽度形成，记录新三项及覆盖 |
| 实际四项齐备且L1=U1 | 产生该相邻DUD的单价位形成 |
| 实际四项齐备且L1>U1 | 排除这一个后移窗口；保留原C0及其他合法来源 |
| R3触原K0 | 按3.2得到新形成的显式共同价格见证 |
| K1非空但未触K0 | 保留新形成事实，不调用“触旧核衔接”标签或复制旧关系 |
| 新旧上沿相等但d/r来源未齐 | 只保存价格门槛相同，不生产三买 |
| 两份d/r依据齐备且上沿相等 | 两份三买严格范围判断可以共用；各自确认时间独立 |
| 新旧上沿不同 | 分别读取相应门槛；不据同端点运输结论 |
| 只有首枢和三买，尚缺107所需完整动力依据 | 不输出已经满足107完整发展条件 |

对本份新形成证明，必要输入是四份材料实际级别/完成/方向、连续组成、原观察及范围。最早可知是这些必要证据在同一相容证明中的最大事件；形成覆盖止于q4，不包含为确认M3结束而出现的后继材料。其他独立更早证明另算。

**依赖已经具体化。** 当前要接通的不是“所有B组”，而是从q3之后的真实行情取得M3的完整覆盖、h级身份、实际下向角色及结束q4。候选生产工作属于规16/20或实际用到的其他完成路径；哪一条成立要继续核证，不能把表中编号当成证明。新核C1不能充当同一个M3的结束前提。

下一工作沿这一生产缺口进入规16联查规20的相应分支，返回目标仍是规02的M3准入及本条形成衔接。107的全域来源裁决仍保持未决，不因为换主项而从清单删除；不再重复“所有情形是否隐含换核”而没有实际对象。

本轮完整关闭的是上述四份实际材料输入域内的相邻形成、条件衔接和范围分支；规02/规05全项不计通过。没有F2源码、业务测试、演示、F1/Bar回放或MACD运行。条件数值与证明不是作者实盘复现。没有新的独立审查结果。
