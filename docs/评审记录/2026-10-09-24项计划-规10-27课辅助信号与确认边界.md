# 规10续：27课限定辅助信号与确认边界

## 1. 正面原文依据及效力

27课在大级别第一/第三下跌比较中，允许黄白线回抽后不创新低与柱面积较小这两个指标依据择一给出背驰信号；两者同时满足更典型。作者将粗级识别与继续向内定位分开，并对具体万科实例作出背驰已经确认的判断。不能删除该正面陈述，也不能将其扩大成所有MACD信号均直接确定精确末端。[27]

24课另有后段完成后的最终面积标准；25课保留辅助指标的限制，特别不能机械解释连续一字板的类似指标波形。前面已证明的“最终面积须读完成覆盖”不能升级为“所有粗级背驰段识别一律先等最终末端”。本轮不以信号认定反过来证明后段完成。[24][25]

## 2. 实际输入及一个明确的执行子域

固定观察、数据版本、实际分解D及27课式第一/第三下向比较P、回升连接R、当前后段Q_u。P已完成；R有真实切点及归属；Q_u有真实起点和有序覆盖，u是已固定数据前缀，不是Q已确认终点。价格、DIFF、DEA与柱值h来自同一固定指标观察K；K的参数、初始化、采样、样本归属及数值可靠性不得跨版本拼接。来源由实际分解取得，不按指标大小挑前段，不用空的source27_allowed字段补来源。[50]

为避免给“零轴附近”发明epsilon，本次仅处理一个更窄的可算子域：对DIFF、DEA各自，P中有负值、R中有非负值、Q_u中又有负值，按P→R→Q的实际时间顺序取得样本见证。这是本文的达/过轴充分子域选择，不是作者要求所有信号必须穿越零轴。仅接近零轴的情形仍未覆盖，不据此判原文不成立。两线见证时刻不要求相同，不插值。

原文的季度图不能直接变成结构级别；本节不将任意同向Z、任意UDU或来源未决的首枢自动纳入27课的大级别比较。规02未决和一般盘整方向问题没有被本节解除。

## 3. 实际判定

用μ_f(W)表示线f在W完整样本覆盖内的最小值。定义：

N：low(Q_u)<low(P)。

L：μ_DIFF(Q_u)≥μ_DIFF(P)，且μ_DEA(Q_u)≥μ_DEA(P)。

H：A_-(Q_u)<A_-(P)，其中A_-读取完整覆盖内所有绿柱绝对面积，不取末簇，不正负抵消。

在真实来源与上述回抽子域成立时，输出来源限定的辅助信号：

S27(D,P,R,Q_u,K)=N且(L或H)。

L采用两线同时不创新低的充分子域；不能将两条线之间也改成OR。H的严格数值小于是本合同的精确读取，不把人工“明显”程度另造为百分比阈值。S27是本文明确规定的辅助观察结论，不是精确结构背驰真值，不产生新走势级别、完成、第一类点或高级构件。

## 4. 分支和正确性

共同前提及N已真时：

| L | H | 输出 |
|---|---|---|
| 真 | 真 | 一个S27，保留两份支持 |
| 真 | 假或未知 | S27，由L独立支持 |
| 假或未知 | 真 | S27，由H独立支持 |
| 假 | 假 | 本前缀不满足本节信号，不是精确非背驰 |
| 假 | 未知 | 未定 |
| 未知 | 假 | 未定 |
| 未知 | 未知 | 未定 |

证明就是对已定义N∧(L∨H)的穷尽赋值：一支有正面见证足够，两支均有反证才能否定OR，剩余赋值不能决定。这证明辅助规则按规定执行，不证明它等价于所有结构背驰。未知不会被当假；共同来源、N或回抽缺失也不会被OR绕过。

相等的作用不同：线最小值相等满足本L；面积相等不满足严格H。面积相等而L真仍有信号。N当前为假只说明尚未破前低，不禁止后续N变真。两线之一恶化可以否定L，不能因此否定H。

可靠数值区间：Q最小值下界≥P最小值上界可证明本线不创新低；Q最小值上界<P下界可否定。Q面积上界<P面积下界可证明H；Q面积下界≥P上界可否定H。其他相交界保持未知。没有可靠界的f64比较不自动取得该保证。

损坏数据、版本混用、断裂覆盖或非零区间重用时报输入错误；不能用其推出市场反证。重复证据不新增材料或信号对象。

## 5. 首次可知及终点边界

每个完整分支证明均先联合自己的共同来源、价格、回抽与相应数值证据，再取必要依赖的最大事件。相同实际绑定下，已经成立的分支取最早完整证明时间：H在55齐、L在70齐、共同条件50齐，则S27首次55，不是70。不得用I的回抽与J的面积拼接。

S27(...,u)针对固定前缀u。Q继续生长可使新前缀信号不再满足，这不删除旧前缀曾出现辅助信号这一事实；但本节没有任何信号到未来完成的授权。若u以前的数据或实际归属被修订，撤回真正失去支持的历史派生，独立有效支持不受连坐。

Q最终独立确认止于e时，最终面积只读[s,e]，发布时间可以晚于e。当前信号不提供这个e。27课在其实例中给出的3.2与3.12及识别后继续定位的叙述保留；本轮没有原图/价格/指标复现，不编造首次破价事件或分钟级终点。原文也说明有限级别收缩未必达到数学极限意义的唯一点。[27]
