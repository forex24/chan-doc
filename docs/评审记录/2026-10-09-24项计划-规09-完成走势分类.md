# 规09：完成走势分类与级别约束

2026-10-09。本聊天24条业务＋4项工程计划。本轮先将规02从全项闭合恢复未闭合，再对原清单的规09进行独立分类论证；没有修改E34、其他生产策略或源代码。主稿的本地改写在§5、§7，远端主稿尚未同步；本文件是本轮可独立核查的规则记录。

## 1. 命题和原文

给定结束边界已有独立依据的实际覆盖W，在指定分解D中，判定能否将W整体确认为一个h级走势；若能，是盘整、上涨还是下跌。本条不寻找终点、不生成中枢、不决定首枢采用UDU还是DUD，也不为盘整生成尚未证明的升降角色。

17/18课以完成为前提，用一个本级中枢定义盘整，用至少两个依次同向的本级中枢定义趋势；18课要求趋势中枢不重叠，20课将要求明确到围绕中枢的实际波动范围。35课说明h级走势必须含h级中枢、至多含h级中枢；43课给出内部高级中枢排除单一h级分类的原则。以下为这些定义的有限判定与证明，不声称原文给出了软件算法。

## 2. 输入和完整性，不使用空的“清单完整=true”

固定W=[s,e]、观察/数据版本O、分解D和待核级别h。W的结束依据给出e和确认依赖，不以本次待证P/T分类自证结束。读取：

| 输入 | 实际依据 | 生产责任 |
|---|---|---|
| W结束 | 实际起终、组成及结束理由；e后确认资料另存 | 规11—16或相应重组完成 |
| 各中枢 | 级别、形成材料、形成覆盖、核心和对W的归属；保留下层内部中枢层级 | 规02—08及相关重组 |
| 横向序列 | 独立前后中枢与同核延伸的区别；连接及切点；另一读法不混入 | 规04、规06、规17—21 |
| 各核波动 | 在W内实际归属各核及其延伸的完整波动范围，不能任意借入移动连接 | 规01、规04—06及实际重组 |
| 分解处理记录 | W内具名生成位置、结果/排除、未决来源/结束/归属及覆盖至哪里 | 各生成规则，工03验证枚举与覆盖 |

完整性检查：展开D的实际次序，形成块、延伸块和连接块必须覆盖W，不漏非零材料；各中枢有独立形成依据；重复支持不新增一个核；W内尚待决定的形成、扩展、归属或重分位置必须列出。位置集合须由已证明枚举规则生成，不能因为缓存为空就宣称不存在其他候选。只核对材料覆盖不漏，也不足以证明所有中枢关系已处理。

若枚举规则、清单边界或必要来源缺依据，正面分类停在具体缺项。107课首枢来源争议不能记为已排除，E34严格策略也不能代替原文覆盖证明。上述上游尚未全部闭合，本条不冒称已完成其生产。

检查仅针对O/D/W及其相关位置，不等待无关分解或未来行情全部确定。甲分解的一核与乙分解的另一核不能拼成同一趋势。

## 3. 级别判定

遍历实际归属W的中枢，读取它们独立取得的递归级别，不从图表周期、时长、幅度或目标类别反推。

若存在g>h的已确认中枢C，全部形成材料在W之内且对D/W归属成立，输出：W不能作为该分解中单一h级走势。见证包括g、全部形成材料及实际包含关系。这条反证不要求高父完成，也不要求其余清单全部齐备。只在价格上触及C，或C的部分形成材料在e之后，不满足内部包含。

不得据此自动将W升级为完整g级走势或选择新的切点；43课给出的可能还包括更高级走势的一部分和多个原级走势的连接。

仅当清单完整、没有相关未决位置时，不存在h级中枢才能排除W是单一h级走势。尚未找到h核不是这个命题。正面分类成立时，h等于W内部中枢最高级别，因为必须有h且不能有更高；但单独取最高级别不能证明整段W是该级别完成走势。

## 4. 类型算法

取D/W中实际独立的h级中枢序列C0…C(m−1)。同核延伸不增加m，同一核的重复支持不增加m，内部h−1核不增加m。相邻滑窗或不同读法没有横向关系依据，不能成为该序列的两项。

对Ci，令Pi为本次判定中实际归属其及其延伸的波动区间集合，计算完整外围：

Ei=[ai,bi]，ai=min low(Pi)，bi=max high(Pi)。

Pi与范围必须齐备。这既不是只有核心，也不是整个W的一个大包络。复用DD/GG须证明确实覆盖本次需要的全部波动；不能将仅同向Z的统计直接当作全部归属材料范围，忽略会改变外围的反向材料。

在W结束有独立依据、清单及归属完整、无内部更高级中枢时：

| 条件 | 输出 |
|---|---|
| m=0 | 不符合单一h级定义，不降级猜测 |
| m=1 | h级盘整；保留起终及组成，不附赠盘整上/下方向 |
| m≥2且每个相邻i满足a(i+1)>bi | h级上涨趋势，附全部相邻上移见证 |
| m≥2且每个相邻i满足b(i+1)<ai | h级下跌趋势，附全部相邻下移见证 |
| m≥2且上述两项全称条件均不成立 | 当前完成断言、横向清单及单一h级分类不能同时成立，返回相交或反向见证；不兜底叫盘整 |

拒绝不是第四种市场走势，也不是行情非法，只否定当前整体划分/级别组合。不能把两个独立核改名成一个核以绕过定义。

趋势方向来自中枢序列移动，不取W净涨跌或首核UDU/DUD相位。首核合法来源仍须规02独立交付，不能先叫上涨，再反推首枢合法。

## 5. 完整证明

### 5.1 方向互斥

若相邻两非空区间同时满足a(i+1)>bi与b(i+1)<ai，就有ai≤bi<a(i+1)≤b(i+1)<ai，矛盾。因此一条边最多属于一个严格方向。

### 5.2 相邻足以推出全部不重叠

若每一相邻关系向上，由a(i+1)>bi及各区间下端≤上端，逐步得到任意i<j均有aj>bi。所有后枢的波动范围都严格高于前枢，非相邻重叠也被排除。向下镜像。

反之，若整个实际中枢序列依次严格上移/下移，所有相邻对当然满足对应条件。因此在完整输入域内，趋势分支对相应方向既必要又充分；再结合17/18类型定义与20范围要求，得到输出。

### 5.3 失败穷尽及见证

某条相邻边两向均不严格时，两闭区间相交，J=[max(ai,a(i+1)),min(bi,b(i+1))]非空。否则所有边都严格分离；若不能全上或全下，必能找到两条相反方向的边。两类穷尽失败。相切属于非严格分离，不加epsilon。

m=1由17/18定义给盘整，但没有因此取得高级组合中的盘整方向。m=0与35课的本级存在要求冲突；内部更高级核与35/43的上界要求冲突。

正面类别不是输入：完整资料也可能落入m=0、重叠或反向失败分支，故未将目标分类放回前提。完整清单的取得是明确的上游生产责任，不是本条已证明能从任意行情取得。

### 5.4 规模

本分类只需顺序读取现有清单与波动范围，外加m−1次相邻比较。其O(清单规模)不包括实际中枢生成、全部候选覆盖、多义性及来源匹配，不是全F2线性结论。

## 6. 分支顺序和缺证

1. 本次使用的证据数值损坏、错版本、覆盖断裂：报输入错误，不用损坏记录推出正反结论。
2. 可独立核验的高级核确在W内：立即排除单一h级，不等其余无关缺项。
3. W缺结束依据：不发布完成P/T；保留结构事实，不预测永不结束。
4. W结束已证，清单/横向关系/相关波动/来源未齐：列具体缺项。只有一个已确认核不等于完整清单只有一核。
5. 全部资料齐备：按类型表唯一分支输出，不等高父、未来走势或其他无关解释消失。
6. 重复支持仅补证；重分改变组成则对新D重新判定，不能悄改旧D的计数。

## 7. 确认时序

正面证明读取W结束、完整源内清单、各核形成/归属、横向连接及完整外围，其known取同一完整相容证明内必要依赖的最大事件。多证明先各自联合，不能拼边际最早时间。

高级核排除只读其必要依赖，不额外等待正面分类的整份清单。输出仍是W原[s,e]，不把获知事件改成e。W在80结束，到100确认结束，到120才齐备完整中枢清单，则该证明在120确定类别，W仍止于80。90—120的后继确认材料不计入W或其外围。

同一数据版本、固定W和完整D下，后续数据不改变这些范围。数据错误或合法重组改变组成时核对受影响依赖；修订执行细节由工01完成。
