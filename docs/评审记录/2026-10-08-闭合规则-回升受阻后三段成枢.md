# 闭合规则：回升终点回入前跌价格带后的三段成枢

日期：2026-10-08。性质：原文定义下的有限业务产生式及完整证明；不是F2整体签收。仅用作者原文，不用旧项目类型、规则编号或人工274例作为前提。

## 1. 原文依据和本次解决的问题

第49课末段讨论：三买之后出现一次实际次级向下，其后的次级向上不能创新高或出现相应背驰时，会引出新的本级中枢。第53课从二类点解释其几何原因：后面还会有一份次级走势，和前两份构成重叠。第18课给出三份连续完成次级走势的成枢定义；第53课要求高级观察读取每份走势的整个高低范围。

本节只闭合其中可以不用力度证明的价格分支：**回升的实际终点落入前一下跌的起止价格带。** 这个条件不是用任意历史高点判断“不创新高”；它明确读取前一下跌的实际起点。若回升全过程最高价也不超过这个起点，则必在本域内；若只是末端回入、内部曾越过，下面的几何证明仍成立，但不能把它另称为原文的全过程不创新高。

本节交付形成位置、公共区间见证、精确核心和发布条件，不只是“将来可能有中枢”的提示。不讨论该新核与前核最终形成趋势还是级别扩张，不给整个本级走势补完成。

## 2. 完整输入与确定输出

选择固定观察精度及同一实际分解。D、U是其中两份已经完成、真实相邻的h级走势，实际端点依次为：

`D：x→y；U：y→z`，满足`x>y，y<z≤x`。

本次形成窗只取紧接D/U的下一份实际h级向下走势V：`z→w`，其实际结束满足`w<z`。三个时间区间按其实际切点相邻，不跳项、不重复占用形成材料。D/U/V的完成、同级性和连续性是递归输入，不能从本节待产的高核反推；三条临时折线或仅有较低级内部转折不满足输入。

记真实完整范围为`R_i=[l_i,u_i]`。不要求这些范围等于起终点区间，也不要求实际起终点是全高或全低。

**输出：** V完成证据和该三项输入的实际对应齐备后，形成这一指定窗口的h+1级中枢，核心为：

`K=[max(l_D,l_U,l_V), min(u_D,u_U,u_V)]`。

本节证明K必有正长度。形成覆盖是D的真实起点至V的真实末端，形成材料就是D/U/V。不另外等待第四份形成材料，不要求V跌破y，不要求MACD或盘整背驰来补这条成枢结论。

这是三个已完成h级走势→h+1中枢，不是三个片段→已完成h+1走势。来源只用已有实际分解，不增加抽象的“目标形成许可已成立”前提。用于第49课后中枢场景时，D/U还须实际处在该原中枢三买后的相应移动中；本节不生产或猜测这份历史三买，也不把任何三元组称作全局最近中枢。

## 3. 完整证明：给出一个正长度公共区间

由完整范围必包含其实际起终价，得到：

`[y,x]⊆R_D；[y,z]⊆R_U；[w,z]⊆R_V`。

令`J=[max(y,w),z]`。因为`y<z，w<z`，所以J具有正长度。又因为`z≤x`：

- J包含于[y,x]，因其下端≥y、上端≤x；
- J包含于[y,z]；
- J包含于[w,z]。

因此`J⊆R_D∩R_U∩R_V=K`，从而K非空且具有正长度。结合第18课的连续同级完成前提，这就是该窗口成枢的充分证明。

未知内部极值只可能使实际范围大于上述端点区间，不会删除J。因此不需要将三个范围强行端点化。精确K仍按真实范围计算；J只是保证存在的公共区间，不能替代K。

证明不依赖V必须创新低，也不依赖V具体包含几个更低级中枢。它只使用V已经实际完成及已给的方向／端点条件。证据无循环：下级完成与连续关系→范围包含→成枢，而非高核→补下级完成→高核。

## 4. 实際动作、失败分支和最早可知

| 实际输入状态 | 本规则动作 |
| --- | --- |
| D/U已完成，回升满足y<z≤x，但V未完成 | 记录这一明确相邻窗口及必重叠的证明条件；不发布已形成中枢 |
| D/U/V完成、同级、连续及所列端点条件均成立 | 直接计算K并发布该窗口中枢；不得另加V破y或背驰门 |
| 所谓V只是低一级对象，或跳过了真实紧邻项 | 不满足本规则输入；不得补标成h级或更换相邻项来通过 |
| 同一证明混入别的分解的切点、重复覆盖 | 拒绝这份不连续／混用的证明，不否定其他独立合法分解 |
| z>x，或零净位移等落在本文域外 | 本条充分规则不适用；不能据此宣称三项不成枢，应另按实际三交判断 |
| 价位、实际完成或对应关系尚缺 | 等待具体缺项；缺证不作为几何为空，也不推动任意右移 |

在固定这份完整证明下，设D/U/V完成和源内连续关系的获知事件分别为k_D、k_U、k_V、k_S，范围记录另有确认依赖时也计入。其首次可发布事件为这些实际依赖的最大值；历史形成末端仍取V的真实末端。确认V用到其末端之后的材料时，不将确认材料并入V范围。

不以别的分解的较早证据替本证明补时间；其他独立构造能否更早识别中枢，是另一个命题。本节不增加九段升级的等待规则。

## 5. 边界核验与镜像

以下为声明结构前提后的区间核算，不是从价位识别出完成走势，也不是Bar/F1/F2运行。

**正常例及非极值端点。** D为120→100、完整范围[98,124]；U为100→110、完整范围[99,118]；V为110→105、完整范围[103,112]。J=[105,110]，精确K=[103,112]。V没有跌破100，仍已成枢。只用端点会错把J当作K。

**端点回到原起点。** D为120→100、U为100→120、V为120→110，完整范围分别取端点区间，得到K=[110,120]。z=x允许，且核心仍有正长度；不涉及三类点的相切争议。

**域外不能反向拒绝。** D=120→100、U=100→130。随后V=130→125且范围为端点区间时，三交为空；V=130→110时，三交为[110,120]。两个结果说明z>x只使本条保证失效，并不等价于不成枢。

**上涨镜像。** D改为向上x→y，U为向下y→z，满足`x≤z<y`；下一实际h级向上V为z→w，`w>z`。则`J=[z,min(y,w)]`具有正长度且包含于三个真实范围的交集，输出同样的精确三交K。镜像由价格取负得到，不新添另一份完成假设。
