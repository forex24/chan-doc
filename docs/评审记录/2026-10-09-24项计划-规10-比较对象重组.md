# 规10研究记录：主导中枢改变后的比较对象重组

日期：2026-10-09。采用本聊天24条业务＋4项工程计划。本轮主项只有规10。**规10整项未闭合，业务计数仍为4/24（规01、规03、规04、规09），工程0/4。** 下文闭合的是规10内部一条原文明确的比较对象生成规则，不新增主编号，不把它冒充全部背驰判定。

## 1. 已闭合子命题：A高于B时，比较a与完整(b+B+c)

**原文。** 第37课明确讨论实际表达`a+A+b+B+c`。A、B不同级时不能用这两个中枢证明该表达为同级趋势；其中A高于B的情况，作者直接改写为`a+A+(b+B+c)`，将a与右侧整体视作围绕A的较低级波动。作者又允许从B的局部视角比较b、c；不同视角不能互相替代。[37]

这里没有把第37课的结论压缩成“先选择正确比较对象”：下面给出被选择的实际覆盖、产生位置、范围和结论权限。

### 1.1 非循环输入

读取同一观察、数据版本和实际分解D的连续表达：

`a ⊕ A块 ⊕ b ⊕ B块 ⊕ c`，

实际切点为`t0<t1<t2<t3<t4<t5`，五块分别覆盖`[t0,t1]`、`[t1,t2]`、`[t2,t3]`、`[t3,t4]`、`[t4,t5]`。

A块、B块是该表达中承载相应中枢及其已归属震荡的实际时间材料，**不是用价格核心区间充作时间块**。A、B的中枢级别、材料归属及表达本身已有独立证据；连接a/b/c及B块属于第37课这份混级表达，不从任意全局记录中凑五项。记`level(A)=h`、`level(B)=k<h`。确认的是所列实际级别，不是“尚未发现B升级所以猜B低于A”。

不得预先输入“右整体已经是完成盘整”“这份比较已经背驰”或“整个S已经完成”。c可以是已界定的完成材料，也可以是有真实起点、当前覆盖明确的生长后段；后一情形只能生成当前比较覆盖，不能发布最终面积或完成。若c的归属连当前前缀也不明确，则保持具体缺项。

a/b/c本身的级别、方向和组成沿用原分解事实；本条不从净涨跌为高级盘整制造方向。只有实际同向比较关系已取得时，才附加相应同向比较用途。若要在同一覆盖内部进一步生成新中枢或完成对象，仍需各自的规则。

### 1.2 正面输出：确定两个比较覆盖，而不是新造走势类型

在上述输入齐备后，生成：

- 被研究中枢：A，级别h，核心保持原值；
- 前比较覆盖：`P=a`，历史覆盖`[t0,t1]`；
- 后比较覆盖：`Q=b⊕B块⊕c`，历史覆盖`[t2,t5]`，组成逐项保留b/B块/c；
- 比较的性质：围绕A的两侧波动比较，可进入相应盘整背驰研究；**此输出不是“盘整背驰已经成立”**；
- 结构性排除：不能继续以这两个不同级A/B，称该五块表达是以A/B为同级中枢的标准趋势，进而直接套标准趋势背驰结论。

Q只是该请求的实际比较覆盖。没有生产一个“专用组合走势”“完成盘整”或任意三项封装，也没有给Q新级别、方向或完成。原有b、B块、c记录不被覆盖，另一合法B视角下的b/c比较可以保留其原作用域。

**反面权限同样具体。** 不准把b/c上已得的面积比较、非背驰、盘整背驰或结束结论直接复制到P/Q；也不能把P/Q的结论回填成原来不存在的同级A/B趋势背驰。相同结束价、相同方向、甚至完整范围相同，都不足以等同两个命题。[37][50][53]

### 1.3 精确范围及保覆盖证明

连接操作只连接实际资料，不交换、不删除、不拆确认单元。令`P(X)`表示一块的有序原资料覆盖，则：

`P(Q)=P(b)⊕P(B块)⊕P(c)`。

由于实际切点相邻，Q恰覆盖`[t2,t5]`。将改写两边逐项展开，都得到原来的a/A块/b/B块/c，顺序一致。连接边界可以共享定位，但不能重复非零材料区间。由此证明该改写保留整个时间覆盖，而非仅保留几个价格。

设三块完整价格范围为`[lb,ub]`、`[lB,uB]`、`[lc,uc]`，则：

`R(Q)=[min(lb,lB,lc), max(ub,uB,uc)]`。

对同一批实际资料，整体最小/最大值等于各分块极值再取最小/最大值，故该式正确。B块范围不是B核心，Q范围不是c范围，也不是三块的交集。[53]

这里用了范围包络计算已给时间覆盖的极值，**没有用包络生产高级核心或完成构件**。第18课的成枢三交与这里计算一个已给比较覆盖的全范围，是不同运算。

### 1.4 全部分支

| 实际输入情况 | 本子规则动作 |
|---|---|
| 数据损坏、范围倒置、块引用错位或覆盖断裂 | 报输入错误，不据损坏材料产生正反业务结论 |
| 级别或A/B与各块的真实归属未齐 | 指出缺项；不按面积大小替它决定主导中枢 |
| A/B同级 | 本条A高于B的改写分支不适用；不得自动证明原表达已经是趋势 |
| B高于A | 不用时间倒置套本条；按那种实际结构另行分析，不据此判行情非法 |
| A高于B，实际块和当前覆盖齐备 | 直接产生P=a、Q=b+B块+c及A视角；无需等整个父走势结束 |
| c尚未完成 | 生成带真实当前末端的比较请求；不得输出Q完整面积或结束 |
| 后来独立证明c止于更早历史位置e | 以该真实末端重定Q覆盖；e后的确认材料不计入Q |
| 只多一份同一表达的证据 | 补支持，不复制b/B块/c，不凑出新的比较段 |
| 合法重分改变A或组成 | 按新实际对应生成另一请求，旧结果保留原作用域；不能仅改标签继承真值 |

有效输入下输出唯一：P、Q、A及其覆盖均由五块位置直接确定。域外分支不声称原文不存在其他规则。

### 1.5 证明的业务效力与确认时间

保覆盖和范围计算由上文证明。为何改为A两侧比较、为何排除该A/B标准趋势身份，来自第37课的明确论述；不是从数学结合律单独推出一个新完成走势。输入并未要求目标比较对已成立，输出则实际构造出Q的组成与边界，所以不是循环许可接口。

对一份完整相容证明p，比较请求的可知事件是：

`known_p(request)=max(所用块及当前覆盖、A/B级别、归属和真实连接的必要证据事件)`。

P/Q的历史切点与这个事件分开。同一完整语义的多份证明各自联合后可取最早，不拼接不同分解的边际证据。最终力度比较另须等待其实际指标定义、计算资料以及所要求的结束或有效前缀条件；生成比较请求不提前授予背驰。

本子命题覆盖第37课A高于B的整个所列结构域，不限于某一组价位；不推广为任何右侧几块都可以吸收，也不声称已经覆盖规10所有比较对象的生成。

## 2. 为什么旧比较真值不能迁移：有可核算的反例

仅为检验命题转换，假定某辅助指标在同一观测和固定方向口径下按互不重复的样本块可加，记其非负面积为S(X)。分界样本归属必须先确定，不能重复计数；这项可加约定不是作者给出的完整背驰定义。

则`S(Q)=S(b)+S(B块)+S(c)`。取两组条件数值：

| S(a),S(b),S(B块),S(c) | 原b/c面积判断 | 新a/Q面积判断 |
|---|---|---|
| 12,10,8,6 | 6<10，后段较小 | 24>12，后段更大 |
| 35,10,8,12 | 12>10，后段更大 | 30<35，后段较小 |

两个方向的翻转均可能。因此“同一行情中某一对比已经否定/支持背驰”不可能不读比较对象就运输到另一对。数字不是市场、F1或MACD运行，亦不证明真正背驰；它完整反驳的是无条件复制该面积关系。

## 3. 第64课给出实际位置核对，不是只选择更大的面积

第64课正文明确：110—111的相应下跌比较对象是104—105，中间采用105—110这个震荡中枢；不能用最近的108—109替代。作者同时保留105—107的另一观察，并解释110尚非该核三卖。[64]

本轮能够核对的原文位置表为：

| 分析中枢/表达 | 前比较覆盖 | 后比较覆盖 |
|---|---|---|
| 105—110这个震荡中枢 | 104—105 | 110—111 |
| 若另考察105—107 | 须按该观察另交材料关系 | 不沿用第一行的完整结论 |

这是对“永远选最近同向段”的原文反例，也说明不能把旧比较失败理解成全行情所有比较失败。但它**不授权向左扫描到第一份面积更大的波动**。新前段的来源是所用中枢与实际分解，不是先看数字再找一个满意的比较对象。

第49课只将最近同向段称为最标准情况；第61课允许围绕同一中枢的两段研究力度。因此多个真实比较请求可以并存，不能为了唯一输出擅自删除其中一种。[49][61]

未取得原图可核像素，本节只依据正文明确的点号指代；没有独立还原各点价格、内部完成和MACD面积。第37课的代数规则与第64课实例各自保留原文输入，不能仅因形似就声称已完整证明二者每个内部构件一一对应。

## 4. 原文明确限定：不能用均线面积替代尚未完成的精确背驰规则

第15课给出均线之间面积的趋势力度定义，并给出面积除以时间的平均力度办法。第25课不是仅在日期上更晚，而是**明确指回以前的“吻”和均线系统**，把它们与MACD一起限定为辅助工具，要求不要与中枢体系混同。[15][25]

所以，不能走以下替代链：

`MACD不是精确规则 → 改用15课两均线面积 → 宣称已经获得完整几何背驰定义`。

第24课有标准结构下的柱面积比较，也有盘中面积估计；第25课还讨论急促走势的柱高/乖离，说明面积较大时仍可能出现对应的超短警告；第27课原例讨论黄白线与柱面积信号；第56课又明确其低于1分钟的实例可只看相应柱面积，1分钟级别则另需看黄白线回抽。这些是有具体作用域的使用方法，不能无证据地统一成全局AND、OR、面积唯一或柱高唯一公式。[24][25][27][56]

数学上，P的面积/峰高为(12,4)，Q为(15,3)，面积和峰高便给出相反的强弱排序。这个例子只说明多个摘要没有自动产生唯一排序，不证明原文自相矛盾，也不否定在已明确子域内采用其中某项。需要证明的是：本次结构到底适用哪一种判据，判据如何足以支持相应业务结论。

**工04与规10的分工。** 工04可以证明某个已选面积算得准确，不能决定面积、柱高、均线形态中的哪项就是本结构的充分判据。那仍是规10的业务义务。第25课的“附近”“一般”“急促”等词，不得偷偷换成固定阈值或epsilon再称作者定理。

## 5. 当前已能确定的背驰判断边界

| 已取得的证据 | 可以确定什么 | 不能推出什么 |
|---|---|---|
| 指定A/B确为不同级 | 这两个核不能充作该标准同级趋势的两核；A高于B时执行第1节重组 | 所有较低级比较都无效 |
| 标准趋势中完整c的次级结构或所含三类点缺证 | 保留具体缺项 | 用面积较小补出c完成或三类点 |
| 完成c在标准上涨比较中未创新高（下跌镜像） | 不成立该标准趋势背驰请求 | 一律没有可研究的盘整背驰 |
| c在生长中尚未创新高 | 尚缺该条件 | 永久排除未来c创新高 |
| 已明确辅助口径下，完整P/Q最终面积可比较 | 输出该口径的较小/相等/较大事实 | 默认等同全部结构背驰或107非背驰向上 |
| 固定追加覆盖的非负面积已超过P | 可用§48证明排除这一面积较小命题 | 排除更早已结束覆盖、不同P或另一中枢的比较 |
| 内层背驰或非背驰成立 | 保留该内层、该比较对象的结论 | 自动复制到父层完整c |

这些边界来自37/49/50/56/61的对象和用途区分。它们不是把未取得的“真实力度”字段包装成已完成算法。[37][49][50][56][61]
